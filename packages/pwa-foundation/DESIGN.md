# 公共设计与交互规范

本文是 `@yefengr/pwa-foundation` 的公共规范，供宿主设计、实现与验收共同引用。它提取已有规则，不另造一套风格；应用文档只补充品牌、业务与布局约束。安装、导入顺序、peer 版本和 API 见 [README](README.md)。

本文自 `0.0.3` 随包分发，`0.0.2` 不包含此文件。本文当前对应 `0.0.4` 的实现能力，版本公开状态以 npm 为准；旧制品与旧版文档不会被回写。`0.0.4` 在原有基础上补充表面/分隔、发丝线检测、通用动效、触控辅助与系统字号读取。下文的“宿主负责”是必须完成的接线，不是包内自动行为。

## 颜色

页面与控件表面采用不透明的中性灰，不使用玻璃材质。强调色用于主操作、文字按钮、链接与焦点，不把大面积阅读背景染成主色。主题支持系统跟随、浅色、深色，首屏尚无 Mantine 属性时按系统深色回退。具体变量定义见 [theme.css](theme.css)，不在宿主另维护一套相同色值。

| 角色（`--pwa-*`） | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `bg` | `#FFFFFF` | `#1E1E1E` | 页面底 |

| `disabled-bg` | `#F0F0F0` | `#2A2A2A` | 禁用底 |
| `tonal` / `tonal-hover` / `tonal-active` | `#EBEBEB` / `#E0E0E0` / `#D6D6D6` | `#404040` / `#4A4A4A` / `#545454` | 次级色调填充 |
| `ink` / `secondary` | `#2A2A2A` / `#606060` | `#F0F0F0` / `#BCBCBC` | 正文／辅助文字 |

正文、辅助文字、强调操作与其背景的对比度至少 4.5:1；输入轮廓对页面与输入表面至少 3:1。装饰分隔不代替可访问名称或状态说明。

## 字体与图标

只用系统字体：界面用 `--pwa-font-ui`，代码与路径用 `--pwa-font-mono`，不下载网络字体；时间与计数使用等宽数字。字重只用 400／600，标题、按钮和标签用 600。字号通过语义 token 引用，不随局部组件另设一套比例。

下表依次为元数据／列表／正文／会话或弹窗标题／页面标题（px）。触控基准由 `pointer: coarse` 决定，不按屏幕宽度判断；窄桌面窗口仍用桌面基准。

| 输入方式 | 标准 | 大 | 特大 |
| --- | --- | --- | --- |
| 桌面 | 13／14／16／18／24 | 14／16／18／20／28 | 15／18／20／22／32 |
| 触控 | 14／16／17／18／28 | 15／18／19／20／30 | 16／20／21／22／32 |

行高：正文 1.65、界面 1.4、页面标题 1.25。输入不低于 16px。不使用 13px 以下字号。只放大文字与同行图标，不放大间距、断点、安全区或点击区。宿主以根元素 `data-pwa-text-size="large"`／`"xlarge"` 选档，移除为标准；系统字号实测与三档映射由包提供；偏好入口、存储键、持久化及回到应用时的重新读取由宿主负责。代码及 Markdown 标题的细分字号仍是宿主补充。

图标使用 Lucide，固定实际线宽 1.5px；按钮内与加粗文字同行的图标为 2px。同行图标 1em，跟随文字档位；TSX 的 `size={16}` 标识同行图标，`size={20}` 标识独立图标按钮（桌面 20、触控 22）。图标按钮仍有 44px 点击区与 36px 圆形视觉底。关闭统一用 Lucide X；只有图标的操作必须有可访问名称。

## 间距

通用间距为 `--pwa-space-2xs…2xl`：4／8／12／16／24／32／48px。可写档位内 px 或引用 token，不是两套取值。同一距离只由一个布局层负责，父级有 `gap` 时不叠加子级同向 `margin`。

| 关系 | 值 | 包与宿主责任 |
| --- | --- | --- |
| 标题与说明 | 4 | 宿主按信息关系布局 |
| 标签与输入、相邻独立按钮 | 8 | 包提供控件样式与确认区按钮间隔 |
| 一般内容到表单主操作 | 16 | 宿主布局；确认区见下一行 |
| Modal 内边距、正文到确认操作区 | 桌面 24／手机 16 | 包提供 |
| 页面大分区／滚动区末尾留白 | 32／48 | 宿主布局 |
| 常规按钮左右内边距／图标与文字 | 16／8 | 包提供 |

领域细档 2／6／10 不能当作通用档位：2 用于双行主副文字与相邻操作槽，6 用于状态图标与文字、紧凑行或附属说明，10 用于紧凑文字按钮与选项标记间隔等已登记关系。应用特有语义继续留在应用文档，不能因包有 token 就认定页面节奏已经统一。

确认操作布局以 768px 区分桌面与手机（CSS 手机 `max-width: 767.98px`，Mantine `sm=48em`）。这与按指针区分字号、按钮高度是两个条件。页面列宽、顶栏、导航、路由与业务卡片布局由宿主负责。

安全区只由实际贴住边缘的布局层计算一次，背景延伸、内容内缩；居中叠层边距取基础留白与安全区的较大值，不相加。包提供四边安全区变量、44px 点击区及浮层安全区 shift 参数，是否实际重定位须在宿主验证，详见 README。

## 圆角、边框与表面

通用圆角 4／8／12／16／24px：小缩略图与行内代码 4，输入、列表行与细指针按钮 8，块级内容与浮层面板 12，页面嵌入容器 16，居中 Modal 24。贴边的整块 Drawer 表面为直角。圆形只用于正圆图形；触控常规按钮用胶囊，细指针且可悬停时用 8px 圆角。嵌套距离不超过 16 时按同心关系取值：外圆角等于内圆角加间距，取已有档位，不缩小内圆角。应用专用气泡、输入卡片与通知形状不在这里统一为业务组件。

| 表面角色 | 规则 | 当前能力 |
| --- | --- | --- |
| 页面中的嵌入卡片 | 以底色差区分，无阴影，不默认描边 | 包有 `card` 与可选 `pwa-surface-card`，不提供业务卡片组件 |
| 内容上方的浮层卡片 | 轻外框与浮层阴影，按表面层级区分 | 包有 `edge`、`shadow-float` 与可选 `pwa-surface-float` |
| 常驻面板 | 比临时浮层更轻，深色可不加阴影 | 包有 `shadow-panel` 与可选 `pwa-surface-panel` |
| 居中 Modal、模态 Drawer | 用表面明度、单层遮罩与模态阴影分离，不额外描边 | 包有 Modal 基础与普通 Drawer 过渡；模态编排仍属宿主 |
| 输入控件 | 1px `control-line`；聚焦加 2px 强调轮廓，边框不变 | 包提供 |

`line` 不替代所有细分隔。行间分隔与浮层外框应区分轻重，0.5px 必须实测能绘制再启用，不能只按 DPR 猜测；包提供 `separator`／`edge` 的常规与发丝线两档，以及可释放、支持密度变化的实测安装器。宿主在入口安装并在卸载/热更新时释放，不另写同语义颜色和线宽。`surfaces.css` 的可选角色只提供外观，不管理布局、Portal 或业务状态。

## 控件与确认操作

基础控件直接用 Mantine，不新增只转发 props 的薄包装，也不提供公共业务确认弹窗。

- `filled` 为主操作（每视图最多一个），`default` 为无边框色调次级操作，`transparent` 为文字操作；`outline` 只作危险入口，最终危险确认用 `filled` 加 `pwa-danger-confirm`。Button／ActionIcon 不传 `color`，由 token 决定颜色。
- 常规按钮：纯细指针且可悬停时高 36，任一粗指针或不可悬停时高 44；独立图标按钮始终 44×44。缩放只发生在内部绘制层，不改变命中区或焦点轮廓。
- 悬停反馈只在 `hover: hover` 下启用，键盘 `focus-visible` 不受限制。标签在输入上方，说明和错误在下方。
- **确认区桌面取消在左、确认在右；手机确认在上、取消在最下，纵向全宽。JSX 根据当前布局生成真实 DOM 顺序，Tab、读屏与视觉顺序必须一致，不用 CSS `order` 或 `column-reverse` 掩盖差异。** `pwa-confirm-actions` 只提供布局，不排序节点。表单的保存／创建与返回操作沿用此规则；业务特例须在应用补充中明确，不能改写公共顺序。
- Modal 表单默认宽 480、确认类 400，由 Mantine `size` 决定，不在 CSS 重写宽度。手机外侧留白为 16px 与左右安全区的较大值。

## 动效

操作反馈保持短促；内容与空间变化用无回弹、柔和收尾的内容曲线。进入与退出分设时长，退出更快，只引用对应时长和曲线 token。

公共时长档位为按下 90ms、快速淡化 120ms、短反馈 160ms、离开 200ms、响应 240ms、返回 280ms、内容淡入 320ms、面板 360ms、出现 400ms。组件 token 只引用档位，具体映射见 theme.css；内容曲线为归一化临界阻尼 `linear()`，标准曲线 `cubic-bezier(0.2, 0, 0, 1)`，退出曲线 `cubic-bezier(0.3, 0, 1, 1)`。Modal 轻移 12px 加淡化、不缩放整层；退出不接收指针。内部按压缩放为 Button 0.98、ActionIcon 0.97，原生命中区不动。

系统减少动态效果时，包把已有时长档位改为 120ms，位移系数置 0，内容曲线改为标准曲线，CSS 只保留短淡化与颜色变化。宿主自行编写的尺寸过渡、循环、滚动和脚本动画也须响应该偏好；循环应在减少动态效果、后台或离屏时暂停，状态文字保留。

包提供通用时长/基础曲线读取、SSR/首次水合一致且监听减少动态效果的 hook，以及 Mantine Modal/Menu/Fade/四向 Drawer 过渡。普通 Drawer 使用内容曲线、不透明纯位移（进入 360ms、退出 280ms）；减少动态效果时只保留 120ms 淡化。路由、历史、消息编排、跟手与阅读器交接仍由宿主管理。

触控按压与无罩浮层外点按保护采用显式作用域与目标安装器，不默认扫描或接管整页，不内置业务选择器。按压仅补绘制、不阻止原生点击和滚动；行延迟 100ms、移动超过 10px 或滚动撤销、短触补显 120ms，释放按 press-out 淡出。取消、失焦、隐藏、禁用、移除及卸载时清理。外点按保留 Mantine 原始关闭事件，仅取消同次触摸的合成点按/焦点；浮层内部、自己的触发器、键盘与鼠标不受影响。宿主负责识别实际浮层/触发器、选择业务目标和释放安装器；没有无罩浮层的应用无需安装外点按保护。

## 关闭、焦点与异步操作

以下均由宿主接线，不是导入样式后的自动保证：

1. 真实 Portal 节点必须位于 `.pwa-ui-scope` 内；宿主决定挂载点、层级与单层遮罩互斥，最上层独占 Escape、遮罩和关闭动作。
2. Mantine 负责焦点陷阱与 `returnFocus`。Modal 实例必须观察到 `opened` 从 true 变 false，不能在关闭同一帧直接条件卸载。退出展示快照保留至真实退出结束，再清理；不以任意定时器模拟生命周期。
3. 打开前记录有效来源与动作后备入口。关闭先让 Mantine 回焦；只有当前焦点仍在 body、html、旧 dialog 或已失效节点时才补救。候选须连接、可见、可用，不在 `inert`／`aria-hidden` 内，用 `preventScroll`；不得夺走用户已经移到有效控件的焦点。
4. 提交用同步 pending 门禁防双击；busy 时确认、取消、关闭按钮、Escape、遮罩与相关重置服从同一门禁。失败留在原上下文，保留输入、错误与重试；普通取消按宿主已有草稿规则清理。
5. 草稿、错误、请求和回执按实际目标隔离。旧请求可以结束原目标状态，但迟到结果不得覆盖新草稿、关闭较新弹窗或劫持当前路由；验收提交仍绑定原交付标识。包不接管业务状态机或数据持久化。

## 可访问性与验收

控件有名称、标签与可见键盘焦点（2px `accent` 轮廓）；低频反馈使用 live region，不靠颜色传达结果，不主动抢焦点。复制须等待真实剪贴板成功，再原位反馈，失败保留手动选择路径；可复用 Mantine CopyButton，不新增同类包装。基本折叠可复用 Mantine，业务自动折叠与阅读位置保持留在宿主。

宿主验收至少覆盖：桌面／手机真实 DOM、几何与 Tab 顺序，打开焦点、Tab 陷阱、Escape／取消／关闭／遮罩回焦，来源消失后的有效后备与不劫持其他焦点，正常／减少动态效果的退出，busy 所有关闭门禁，失败草稿与错误保留，跨目标／导航后的迟到结果，以及真实 Portal 内的样式。截图或结构测试不能单独证明这些生命周期通过；桌面移动视口也不替代真机的键盘、安全区与系统返回验收。

## 公共与宿主能力边界

| 项目 | 归属与下一步 |
| --- | --- |
| 字号三档 | 包提供 token、系统字号实测与映射；宿主接偏好入口/属性、存储及回到应用时刷新 |
| 外观 | 包已有系统／浅色／深色；宿主入口缺项属于接线差异，不需要新主题框架或完整设置页 |
| 边框与表面 | 包提供视觉角色、分隔/外框和发丝线检测；业务状态映射与页面布局留宿主 |
| 通用动效与触控 | 包提供时长读取、普通进出、按压撤销与外点按保护；宿主显式接线，不搬运路由/跟手手势 |
| 复制与基础折叠 | 复用 Mantine；反馈、过渡和焦点按本规范接线，业务自动折叠不公共化 |
| 品牌、权限/API、路由/history、数据持久化、安装/缓存/软键盘策略 | 始终由应用维护；共用体验规则不等于共用业务状态机 |
