2 · 滚动边缘分隔

评审：顶栏只在内容滚到下方时显示一条发丝线。两侧都可以滚动；右侧滚到顶部时分隔会淡出。设置页、电脑 Drawer 与阅读器头部按同一规则。

  • 滚动距离 > 0 时写入 data-scroll-edge
  • 发丝线经 --pwa-duration-fade（120ms）淡入淡出，不改变布局

3 · 同心圆角

评审：外圆角 = 内圆角 + 内边距。红色虚线是由外框圆角推出的同心轮廓：同心时会正好贴住内部圆形或菜单行。附件按钮固定显示悬停底，便于对照。
