会话文件发布说明

Pi 可以把电脑上的成果文件发布到会话。发布保存的是源文件引用，不是副本或历史版本；PWA 按会话权限获取原件。

发布与获取

  • Pi 主动发布面向用户的交付文件，发布记录随原生会话保存。
  • 图片在会话内直接展示，点击进入单张查看；其他文件以文件名、大小和操作组成的轻量文件行展示。
  • 获取由 PWA 发起，Relay 只转发请求与分片，不保存文件内容。

获取上限

文件类型自动获取手动获取
受支持图片≤ 10 MiB10–50 MiB
其他文件不自动手动点击
超过 50 MiB不传输不传输

发布记录示例

{
  "customType": "pi-reach:published-file-v1",
  "file_name": "文件回传链路.png",
  "mime_type": "image/png",
  "byte_length": 880640
}

读取过程只做只读访问，源文件不会被移动或修改；中断后从头发起新的获取。
