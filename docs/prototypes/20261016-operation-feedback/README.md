# Pi Reach 操作状态与摘要展示

状态：评审中（交互基线已确认，本次范围修订供复核）。当前原型按 Pi 1.3.0 公开 API 核对结果收敛；实施范围与规划见[方案](../../plans/completed/20261016-operation-feedback.md)，项目级状态见 [ROADMAP](../../ROADMAP.md)。

打开 [page.html](page.html)，通过顶部的场景、状态和「下一状态」切换效果，右侧按钮切换深浅外观。阅读器打开后先返回会话，再继续切换评审状态。页面无外部资源依赖，可直接在浏览器打开。顶部控制栏属于评审工具，不进入正式产品。

这版原型用于确认三个问题：耗时操作的提示是否容易找到；等待、完成与失败是否能区分；长内容进入侧边阅读器、紧凑操作只显示状态图标后，阅读和操作是否顺手。

## 范围与路径

| 场景 | 可查看的状态与交互 |
| --- | --- |
| 压缩上下文 | 压缩中、成功后阅读入口、侧栏查看摘要、失败、取消、断线后结果待确认 |
| 分支摘要 | 会话内保留阅读入口，点击在侧栏查看摘要原文 |
| 新建会话 | Pi 命令 → `/new` → 既有确认框；确认后在旧会话底部显示压缩同款状态行，新建中 → 打开中 → 目标就绪；命令按钮保持 `/` 图标，等待时禁用重复新建与发送；就绪前保留原会话，失败后仍走原入口重试 |
| 模型与思考 | 标签保留当前值，固定槽位仅显示切换图标；成功显示实际配置；失败示例保留原值，正式实现必须核实实际状态 |
| 停止任务 | 停止按钮原位显示等待图标，不增加说明行；区分已中断与自然完成；失败后恢复停止按钮 |
| 模型列表 | 模型与思考 → 切换模型／思考级别；保留返回、提供方、名称、ID 和选中标记；加载、失败、成功为空，刷新保留已有模型；Escape 回到模型按钮 |
| 本地历史列表 | 加载、读取失败重试、成功为空；刷新及刷新失败保留已有记录；手机通过导航抽屉展示 |
| 模型服务错误 | 会话内显示简短说明，阅读器展示通用恢复建议；不编造状态码或错误代码 |

建议先看「压缩上下文」的进行中与完成状态，点击「上下文已压缩」打开阅读器，再检查分支摘要与错误详情的同一路径。随后看「新建会话」的三个阶段，以及模型切换、停止失败和列表加载。

长内容统一采用现有工具／文件阅读器的布局：桌面右侧 720px，手机占满产品区域。会话内不展开摘要或错误详情；打开阅读器不改变下层布局与阅读位置，关闭、Escape、遮罩或浏览器后退返回会话并恢复入口焦点。手机左上角返回，桌面右上角关闭，阅读器保留复制入口。顶部评审工具不计入产品区域。

模型／思考切换与停止等待只使用图标，保留悬停提示、读屏名称和 44px 控件。模型状态预留固定 16px 槽位，切换时不挤动名称、不撑高输入框；成功后直接呈现新值，不另加成功说明。错误原因、恢复动作、列表加载与空态保留必要的简短文字。所有消息、时间、模型和结果均为固定示例。

## 设计依据与差异

视觉沿用 [DESIGN.md](../../DESIGN.md)：中性灰表面、雾蓝控件、琥珀色进行中图标、绿色成功与红色错误图标；正文仍使用中性文字。压缩与分支摘要为 16px／1.65，进行中状态为 14px。可交互目标至少 44px；有可见键盘焦点。减少动态效果模式取消平滑滚动，加载与运行图标依照现有规范继续旋转。

本次已确认的新增规则是：压缩、分支摘要和长错误详情通过侧边阅读器查看；压缩和新建共用局部状态行，新建等待不遮住整页、命令按钮不重复转圈；模型／思考切换以等待图标替换原下箭头，停止等待使用原按钮；列表加载与成功为空分开。失败使用必要的一次性提示，不另建重试区域。

本次修订按正式 `composer-command-menu.tsx`、`message-composer.tsx`、`workspace-title-bar.tsx`、`confirm-action-dialog.tsx`、`tool-reader.tsx` 及对应 CSS 核对：删除额外标题块和假搜索框，恢复菜单层级、空态、侧栏元信息、输入区边框及禁用样式；模型与思考级别分别更新；手机重连文字保留，取消压缩为中性色；评审说明与产品内容分离。不再沿用前版输入区上方的新建说明块，没有更新设计系统真源。

为便于评审，所有状态可以手动切换；没有真实计时和网络操作。列表的 300ms 延迟／显示后至少 500ms、自动跟随与「最新」恢复、连续事件下的阅读状态保留、中英文切换，以及真实 Mantine 叠层交接、移动端右滑与原生返回动画，均留给正式实现验证。模型列表、手机导航和详情阅读器使用原生 HTML 模拟。

## 边界

仅包含原生 HTML、CSS 和 JavaScript。不会连接 Pi、Relay 或模型服务，不会发送消息、创建会话、切换模型或停止任务。原型本身独立于正式代码；正式实现及其验证范围见上述方案末尾记录。

自动重试演示已移除。Pi 1.3.0 未提供所需的公开 Extension 重试生命周期事件，本次不实施该反馈，也不修改 Pi 本体或上游 API。原型不验证请求关联、断线恢复、事件时序或完成判定；正式实现仍需以各操作的权威回执与生命周期收尾，整轮完成遵循正式 `run_end`。错误阅读器只演示通用说明，不代表已经取得可安全展示的现场长错误。

## 验证

使用仓库已有 Playwright 与 Chromium 检查 1280×900、390×844 和 320×740 三种视口，覆盖全部 42 个模拟状态，共 126 项状态视口检查：无横向溢出、文字容器溢出或小于 44px 的交互目标。另核对各视口中模型／思考／停止状态切换前后的控件坐标与尺寸一致。

交互检查覆盖压缩、分支与错误共用阅读器，按钮／Escape／遮罩／浏览器后退关闭，来源焦点与阅读位置恢复，Tab 留在模态内，背景滚轮不改变会话位置，手机正文真实滚动到末尾；保留新会话阶段、停止失败恢复、模型列表重试／Escape／回焦、导航抽屉、深色及减少动态效果检查。另检查模型与思考级别分别更新、模型菜单层级、`/new` 确认和 `/compact` 入口、刷新保留列表、手机重连的可见说明与读屏名称、取消状态的中性色。浏览器没有页面异常或 HTTP 请求。

已导出 19 张实际浏览器截图，并人工查看关键桌面／手机场景。几何检查只证明原型自身的尺寸与交互，不证明与正式界面逐像素一致；上述组件对照是单独的检查。桌面 Chromium 窄视口检查不等同于 iOS、Android 真机验收，也不代表正式业务功能验证通过。
