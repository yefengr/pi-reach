# 当前 PWA 设计

本文是 Pi Reach 当前 PWA 的视觉与交互规则真源。规则来自 `pwa/src/app/pwa-theme.css`、`pwa/src/app/globals.css`、`pwa/src/app/pwa-controls.css`、`pwa/src/app/workspace-navigation.css`、`pwa/src/app/workspace-shell.css`、`pwa/src/components/pwa/*.css`、`pwa/src/lib/ui/pi-reach-theme.ts` 及现有 PWA 组件；未来原型或主题方案不能覆盖本文。

## 视觉 token

PWA 使用浅色、深色和系统跟随三种外观。页面、表面、选中态与长篇对话都以无彩中性灰（R=G=B）承载；主色为在 Pi Reach「钢雾蓝」基础上提纯的雾蓝，只用于主操作、文字按钮与链接、焦点、单选框选中点和在线／新回复圆点（见 [ADR-20261001](adr/20261001-neutral-surfaces-mist-blue.md)）。token 定义在 [`pwa-theme.css`](../pwa/src/app/pwa-theme.css)：浅色在 `:root`，深色在 `:root[data-mantine-color-scheme="dark"]`；Mantine 在首屏脚本写入属性前，CSS 按系统深色偏好回退到同一组深色值。[`pwa-theme-contrast`](../pwa/src/app/pwa-theme-contrast.node.test.ts) 测试直接读取该文件，校验下文的对比度约束以及深色回退与深色主题一致。

状态色按语义使用，不随组件各自取色：在线与新回复为 `accent` 圆点、文字用中性色；正在执行（运行、连接、重连）用琥珀色加动态图形；思考与工具调用的过程文字保持中性色，运行状态只由动态图标表达；成功结果（工具完成、附件就绪、成功通知图标）用绿色；需要关注的情形（附件暂停、插入未确认、主机截断输出、部分在线）用琥珀色加文字或图标；失败与危险用红色；空闲、离线、排队、已中断、预览缩短与一般说明用 `secondary`。已中断是用户主动停止，不用错误色。例外：标题栏的离线与无网络用中性色，持续断线的提示条可用红色；Toast 保持中性底色与正文，只给图标着色；会话内局部错误条用 `error-wash` 底、`error-line` 边框与错误色文字（见「反馈呈现」）；正常完成时间用 `secondary`；diff 的增删行用完成色与错误色，与执行状态无关。每种状态另有轻底（`*-wash`），实心按钮上的文字用 `--pwa-on-status`（浅色白字、深色 `#1E1E1E`）。状态必须同时有文字或图标，不能只靠颜色。

| 状态 | 浅色文字／轻底 | 深色文字／轻底 |
| --- | --- | --- |
| `complete` | `#347953` / `#EAF3EC` | `#95CBA8` / `#26392E` |
| `running` | `#90611F` / `#F9F2E6` | `#DFBA77` / `#3D3528` |
| `error` | `#AE463E` / `#F8ECEA` | `#EFA39B` / `#422F30` |

危险实心按钮悬停／按下为浅色 `#973B34`／`#82312C`、深色 `#F4B2AC`／`#F8C4BD`。

对比度约束（由测试校验）：`ink`、`secondary` 在全部中性底上 ≥ 4.5:1，`soft-ink` 在主要阅读底上 ≥ 4.5:1；`hover` 对 `bg`／`panel`／`surface` ≥ 1.10:1，`neutral-active` 对 `hover` ≥ 1.08:1，`selected` 对 `panel` ≥ 1.14:1 且不与 `hover` 同值，`disabled-bg` 不与 `hover` 同值；`accent` 在 `bg`／`surface`／`panel`／`hover` 上及 `on-accent` 在三档强调底上 ≥ 4.5:1；`control-line` 对 `bg`／`surface`／`panel` ≥ 3:1；状态文字对各自轻底、`on-status` 对实心状态色 ≥ 4.5:1；代码底上的文字与深色强调色 ≥ 4.5:1。

### 基础层

| 项目 | 规则 |
| --- | --- |
| 字体 | 只用系统字体，不下载网络字体。界面 `--pwa-font-ui`（`-apple-system`、`Segoe UI`、`PingFang SC`、`Microsoft YaHei` 等），代码与路径 `--pwa-font-mono`（`ui-monospace`、`SF Mono`、`Menlo`、`Consolas` 等）。时间与计数使用 `tabular-nums` |
| 字号与行高 | 16px 基准：元数据 13、侧栏列表 14、正文 16、代码 14、会话标题 18、页面标题 24（px），不使用 13px 以下字号；桌面与移动端输入框均不低于 16px。行高正文 1.65、界面文字 1.4、代码 1.55 |
| 字号档位 | 设置页提供标准／大／特大三档，只放大不缩小：标准为上述基准；大档元数据 14、侧栏列表 16、正文 18、代码 16、会话标题 20、页面标题 28；特大档 15／18／20／18／22／32（px）。行高保持倍数；间距、图标、44px 点击区、断点与安全区不缩放。输入框跟随档位且不低于 16px；Composer 单行高度取 `max(44px, 一行文字高度 + 上下内边距)` |
| 字号语义 | 以下为默认档；切换字号档位时按「字号档位」整体放大。侧栏列表和表单选项标签为 14px／600；弹窗与配对正文、压缩和分支摘要为 16px／1.65，排队消息正文为单行 16px／1.4；加载说明、Toast、只读说明与操作文字为 16px／1.4；会话内 Working 提示为 16px／600／1.4、运行色；思考标题为系统字体 16px／600／1.4、斜体，工具组头的工具名与摘要为系统字体 16px／600／1.4，组头命令与路径为等宽 16px；展开的思考正文为系统字体 14px／1.65、斜体、`secondary`，展开的工具名为系统字体 14px／600／1.4，命令与路径为等宽 14px；图片省略说明与配对连接状态为 13px／1.4；阅读器命令标题与行内代码为等宽 14px／1.55 |
| 局部尺寸例外 | 不计入间距档位：消息区底部 `88px`（浮动「最新」入口避让）、主区空态顶部 `clamp(48px, 24dvh, 260px)`（上限与侧栏宽度无关）、行内代码／命令胶囊 `1px` 纵向内边距；收起侧栏后标题保持主区 gutter |
| 字重 | 只用 400 与 600；600 用于标题、会话名、分组与状态标签、按钮文字。正式 CSS 引用 `--pwa-weight-regular`／`--pwa-weight-strong`，字号引用 `--pwa-text-*`，不写字面量（输入框 `max(16px, …)` 下限除外） |
| 字形 | 斜体只用于思考标题与思考正文（其中代码与操作文字保持正体）、Markdown 强调，以及代码高亮的注释与强调；其他文字不用斜体 |
| 间距 | 通用档位 4／8／12／16／24／32／48、领域细档 2／6／10；关系映射、语义 token 与执行边界见[「间距」](#间距) |
| 圆角 | 通用圆角只用 `--pwa-radius-xs/md/lg`（4／8／12px）：标签、行内代码与小缩略图 4；按钮、输入框、列表行、消息、独立内容图片、代码块、工具输出容器、Popover、Menu、Toast 8；桌面主区卡片（侧栏展开时）、Modal 12。Composer 独立使用 `--pwa-radius-composer`（16px），不改变其他表面。侧栏、移动导航与电脑选择 Drawer、工具和文件阅读器 Drawer、设置页在静止、转场与跟手拖动期间均为直角；其他贴边整块表面也为 0（见 [ADR-20261028](adr/20261028-square-navigation-and-drawers.md)） |
| 阴影 | 阅读背景和普通消息保持平静：侧栏、桌面主区卡片、消息与设置分区不用阴影。Composer 是主要操作表面，浅色用 `--pwa-shadow-composer`（`0 2px 12px var(--pwa-shadow-color)`）轻抬升；深色为 `none`，靠明度与边框区分。浮层（Popover、Menu、Toast）用 `--pwa-shadow-float` 加 1px `line` 边框；模态（Modal、Drawer）用 `--pwa-shadow-modal` 加 `scrim`，不再额外描边，由遮罩与明度提供分离；设置页仅在转场与跟手拖动期间同样使用，静止时不带阴影 |
| 焦点 | 所有控件 2px `accent` 轮廓，默认贴边绘制（偏移 0）；细指针菜单行的视觉底内缩时，轮廓同步内缩 2px，完整命中区不变。Mantine 自带焦点环关闭，由全局 `:focus-visible` 统一 |
| 滚动条 | 全应用滚动区统一 `scrollbar-width: thin`、`scrollbar-color` 为 `control-line` 滑块 + 透明轨道；由 [`useScrollIndicator`](../pwa/src/lib/ui/scroll-indicator.ts) 在滚动时标记、停止 3s 后隐藏，显示只作用于被滚动的那个容器（脚本就绪后每个元素自身取透明、不靠继承，切换时只重算被滚动的容器），出现与消失用 `--pwa-duration-fade` 淡入淡出，过渡只挂在真正滚动过的容器（`data-scroll-host`）上以免覆盖组件自身的布局过渡，自带 transition 的滚动容器（如消息列表）在自身声明中补上 `scrollbar-color`；加载更早记录期间（`data-scroll-hold`）抑制显示，不用 `scrollbar-width: none` 移除滚动能力；脚本未就绪（无 `data-scroll-hints`）时滚动条保持可见。滑块长度由浏览器按内容比例绘制，没有过渡。消息区保留 `scrollbar-gutter: stable`，显隐不改变正文宽度 |
| 断点 | 主布局仍以 768px 区分桌面与移动：正式 CSS 写作 `max-width: 767.98px`，脚本只用 [`viewport-queries.ts`](../pwa/src/lib/ui/viewport-queries.ts) 的 `MOBILE_LAYOUT_QUERY`／`DESKTOP_LAYOUT_QUERY`，Mantine `sm` = 48em，三处由守卫对齐，不另设宽度断点。组件另按自身容器和输入能力适配：窄桌面面板不等于宽布局，大视口也不代表只有鼠标 |
| 动效 | 曲线、位移、进出模式、循环与减少动态效果见[「动效」](#动效)，时长取值见[「动效时长」](#动效时长) |
| 悬停与触屏 | `:hover` 反馈（`hover` 浅底、颜色变化）只写在 `@media (hover: hover)` 内，避免触屏点击后残留悬停态；需要按下反馈的行（如折叠头）另用 `:active`，松手即消失。取消 Mantine 默认悬停样式或保持选中态的覆盖规则不受此限，由 [`pwa-style-guard`](../pwa/src/app/pwa-style-guard.node.test.ts) 逐条登记。只在悬停时显示的入口，在 `(any-pointer: coarse), (hover: none)` 下常显，不按视口宽度判断。键盘 `:focus-visible` 不受影响 |
| 图标 | Lucide，经 `LucideProvider` 统一线宽 1.8；尺寸只用 16（按钮内、元数据、状态行）、20（图标按钮与导航）、24（空状态等大尺寸）。例外：与 13px 状态文字同行的运行中旋转图标为 12（连接状态、导航行、输入区提示行、更早记录加载提示），线宽 2.4，使实际线宽与 16 图标一致，全局线宽与 12 档取值为 [`icon-metrics.ts`](../pwa/src/lib/ui/icon-metrics.ts) 的具名常量；TSX 中 Lucide 图标的 `size` 只写 16／20／24 或该常量，`strokeWidth` 只引用这些常量，由守卫校验。同一含义只用一个图标：重试与刷新为 `RefreshCw`，恢复默认（重置布局、还原缩放）为 `RotateCcw`，操作菜单为 `Ellipsis`，只读信息为 `Info` |
| Mantine | [`piReachTheme`](../pwa/src/lib/ui/pi-reach-theme.ts) 的字号、标题字重、间距（2xs–2xl 依次为 4／8／12／16／24／32／48）、圆角与阴影引用上述 token，`ActionIcon` 默认尺寸引用 `--pwa-hit-target`；Mantine 圆角 `xs` 对应 4，`sm/md` 同为 8，`lg/xl` 同为 12，不额外增加档位。断点以 em 字面量对应 768px；`piReachCssVariablesResolver` 把 Mantine 语义颜色变量（body、text、dimmed、default、primary、disabled、overlay 等）映射到同名角色，不维护平行色值。Mantine 必须写实际色值的 `white`／`black`（浅色 `bg`／`ink`）与雾蓝色阶（浅色主色第 6–8 档为 `accent`／`accent-hover`／`accent-active`，深色主色第 3 档为深色 `accent`）由守卫与 token 对齐 |

### 图片圆角

图片按展示角色取圆角，不按来源、原始尺寸或 `preview` 属性区分：

- **小缩略图 4px**（`--pwa-radius-xs`）：附件卡片中的 32px 缩略图与排队消息中的 24px 缩略图；解码失败后的文件图标占位保持同形。
- **独立内容图片 8px**（`--pwa-radius-md`）：消息图片、Markdown 图片、工具输出图片（包括受限预览和完整阅读器）、已发布文件的嵌入图片与可缩放阅读器图片。已发布图片的几何过渡层同用 8px，避免与静止图片的形状规则不一致。

圆角只改变展示，不改变图片尺寸、`object-fit`、缩放、拖动或资源生命周期；内容图片即使原图很小，也不自动改用缩略图圆角。

### 嵌套、圆形与胶囊

- **嵌套不递减**：表面内的子表面沿用自身角色的圆角，不按「外层圆角减内边距」递减。菜单面板（8，内边距 6）中的菜单项、电脑面板中的电脑卡片同为 8；递减后的 2 不在圆角档位内。
- **圆形 `50%`**：只用于正方形或正圆元素，包括图标按钮及同形入口（移动端返回、移动端菜单图标、Composer 工具图标）的 36 悬停底与焦点轮廓、发送与停止按钮、在线／状态／新回复圆点；单选圆点沿用 Mantine 默认圆形。
- **胶囊**：开关沿用 Mantine 默认的全圆角，进度条高度不超过 8，取 8 后两端即为半圆；两者都不另设 token。Tooltip 与 Popover 同为 8。

### 间距

通用档位定义为 `--pwa-space-2xs…2xl`（4／8／12／16／24／32／48px）。档位值可以写 px，也可以引用 token；token 供 Mantine、脚本与跨文件语义引用，两者不是两套取值。

| 关系 | 值 | 说明 |
| --- | --- | --- |
| 标题与说明 | 4 | 强关联文字 |
| 表单标签与输入框、单选卡片之间、相邻独立按钮 | 8 | 控件本身与同级操作；横排与纵向同值 |
| 一般内容到表单主操作 | 16 | 表单内部 |
| 弹窗内边距 | 桌面 24、移动 16 | 配对、重命名与确认同值 |
| 弹窗正文到底部操作区 | 桌面 24、移动 16 | 按视口切换 |
| 页面大分区 | 32 | 设置分区、主区大块 |
| 页面底部留白 | 48 | 滚动区末尾 |
| 只读信息块行距 | 4 | 会话信息弹层的名称／路径／元数据 |

主副文字按所处层级取值，不按字号临时调整：同一控件或列表行内的主副文字为 2（见下方细档）；同一信息块内的标题与说明（设置分区、只读信息块）为 4；以大号标题引出的独立说明（主区空状态、启动失败页）为 8，并由说明的上外边距负责。

领域细档 2／6／10 只用于下表列出的语义，不作为通用档位；新语义需要细档时先补进本表，语义漂移时按关系重新取值，不新增第四档。有 token 的语义可以引用 token，也可以写 px：

| 名称 | token | 值 | 适用 |

执行边界：

- CSS 间距字面量必须落在通用档位或领域细档内；其余值（如消息区底部 88、主区空态上限 260、收起侧栏避让 56、附件元数据 3）在 [`pwa-style-guard`](../pwa/src/app/pwa-style-guard.node.test.ts) 按文件、选择器与属性登记取值和理由。
- 守卫扫描间距属性、名称含 `pad`／`gap`／`margin`／`inset` 的自定义属性、十六进制色值与边框宽度，并拒绝不再需要的登记：登记值必须至少有一个超出通用档位与领域细档。
- 圆角守卫固定通用 token 为 4／8／12px、Composer 为 16px；正式 CSS 的圆角只允许引用这些 token、使用贴边 `0`、圆形 `50%` 或 `inherit`，Composer token 仅用于输入卡片。历史开发评审样式不受该圆角用法限制。
- 守卫另检查正式 CSS 的字号与字重（含 `font` 简写）只引用 `--pwa-text-*`、`--pwa-weight-*` 或 `inherit`，见「基础层」的字重规则。
- 正式 CSS 不写 `44px`：点击区及与之同高的行、输入框引用 `--pwa-hit-target`（见[「按钮尺寸」](#按钮尺寸)）。
- 正式 CSS 的 `translate` 函数与属性不写非零 px 字面量：位移引用位移 token 或百分比（见[「动效」](#动效)）。
- 脚本侧由 [`pwa-script-token-guard`](../pwa/src/app/pwa-script-token-guard.node.test.ts) 校验断点查询、Lucide 图标尺寸、动效回退时长、动效 token 只经公共函数读取，以及 Mantine 色值副本；其余 TSX 内联样式与 Mantine props 仍靠评审。守卫都只防止字面量回退，不替代盒模型与行为测试。
- `top`／`right`／`bottom`／`left`／`inset` 等定位偏移属于几何对齐（如圆点角标、收展入口定位），不受间距档位约束，守卫也不扫描；定位偏移用来表达元素之间的距离时（如 Composer 菜单与输入卡片相距 8），仍按档位取值。

### 动效

动效只表达状态的来去与空间关系；本节是曲线、位移、进出模式与减少动态效果的唯一来源，时长取值见[「动效时长」](#动效时长)。

- **曲线**：只用标准 `cubic-bezier(0.2, 0, 0, 1)`、进入 `cubic-bezier(0, 0, 0, 1)`、退出 `cubic-bezier(0.3, 0, 1, 1)`（`--pwa-ease-standard/enter/exit`）。标准曲线用于按压、局部图标反馈及屏幕内移动或改变尺寸（侧栏收展、折叠展开、设置页滑入／滑出、Drawer 进出）；进入／退出曲线用于 Modal、Popover、Menu、Toast 以及浮动入口与局部提示的出现与离开。`linear` 只用于无限循环（旋转、骨架呼吸）。
- **时长**：只引用 `--pwa-duration-*`；同一元素的出现与离开分设时长时，离开更快。
- **位移**：距离只引用下表 token，或按元素自身尺寸取百分比，并乘以 `--pwa-motion-shift`；正式 CSS 的 `translate` 不写非零 px 字面量。

  | token | 值 | 用途 |
  | --- | --- | --- |
  | `--pwa-overlay-shift` | 8px | 居中 Modal、Toast、浮动入口进出 |
  | `--pwa-menu-offset` | 4px | 菜单沿实际定位方向的位移 |
  | `--pwa-message-shift` | 6px | 新发送气泡从下方进入 |
  | `--pwa-collapse-shift` | 4px | 折叠内容收起时上移 |
  | 自身尺寸 `100%` | — | Drawer、设置页、工具组轮播文字，不另设 token |

- **覆盖模型**：Drawer（移动导航、移动电脑选择、工具与文本文件阅读器）与设置页转场统一为 200ms 标准曲线纯位移、进出同长，只有上层面板移动，下层视图保持原位，面板全程不透明、不叠加淡化，遮罩以同一时长与曲线同步淡化。图片阅读器使用局部图片几何与原位淡化（见「组件规则」的文件阅读器）。
- **叠层**：Modal、Popover、Menu、Toast 以进入／退出曲线淡化；Modal 与 Toast 另位移 `--pwa-overlay-shift`，菜单位移 `--pwa-menu-offset`，不缩放整层以免压缩命中区。各叠层的细则见「组件规则」的表单与叠层、菜单与弹窗、反馈呈现。
- **浮动入口与局部提示**：「最新」／「N 条新输出」、「重试」、连接提示条、局部错误条、运行时提示条出现时淡入（`toast` 时长、进入曲线），消失时淡出（`fade` 时长、退出曲线），淡出期间不可点击、不可聚焦，也不再被读屏播报；浮在内容上的入口另从下方 `--pwa-overlay-shift` 位移进出，占布局的提示条高度一次到位、只淡化；文字或计数变化原位更新、不重播，出现或消失中途反向时从当前透明度继续。由 [`usePresence`](../pwa/src/components/pwa/use-presence.ts) 与 `.pwa-presence` 实现，不支持 `@starting-style` 的浏览器直接显示。
- **内容切换**：会话内容切换只淡入、不加位移（见[「实时与只读历史」](#实时与只读历史)）。
- **输入区内的增减**：附件卡片与排队消息面板在输入区内的增加与移除即时完成，不做进出动画。它们与发送时的输入区回缩共用高度，叠加过渡会和发送过程互相干扰。
- **平滑滚动例外**：「最新」使用浏览器原生平滑滚动，时长与曲线由浏览器决定，不受 token 控制；长距离分段见[「可访问性与动态效果」](#可访问性与动态效果)。不自行逐帧驱动滚动：iOS 上逐帧写入 `scrollTop` 会和系统惯性争夺位置。
- **循环**：加载、运行中和骨架等循环只在页面前台且元素位于可见区域时运行；离屏、页面隐藏或系统减少动态效果时暂停，状态图标、文字与业务时钟保留，重入不重播历史状态。
- **减少动态效果**：只跟随系统 `prefers-reduced-motion`。[`pwa-theme.css`](../pwa/src/app/pwa-theme.css) 的全局规则把 `--pwa-motion-shift` 置 0，所有非循环时长改为 `--pwa-duration-reduced`（120ms），过渡只保留颜色与透明度，`scroll-behavior` 改为 `auto`；位移、缩放与尺寸过渡因此取消，只剩短淡化，设置页与各 Drawer 改为淡化。脚本侧，时间线视口经 `viewportMotionAllowed` 判断，「最新」改为瞬时滚动，发送时输入区回缩与贴底即时完成；跟手拖动经 `pwaMotionShiftDisabled` 判断，退回松手一次判定。循环暂停，见上条。
- **脚本取值**：时长经 `usePwaMotionDuration`（订阅偏好变化）／`readPwaMotionDuration`，曲线与位移开关经 [`motion.ts`](../pwa/src/lib/ui/motion.ts) 的 `pwaStandardEasing`／`pwaMotionShiftDisabled`；调用点不自行解析 `--pwa-duration-*`／`--pwa-ease-*`，由 [`pwa-script-token-guard`](../pwa/src/app/pwa-script-token-guard.node.test.ts) 校验。

| `status-backdrop` | 500 | 主屏 PWA 状态栏背景条：只供 iOS 取色、不绘制也不接收点击，位于所有叠层之上才能被取样命中 |

遮罩始终只有一层：Modal 叠在带遮罩的 Drawer 上时下层遮罩隐去。

### 品牌资产

标识为「桥」：单色几何 π，一体化横梁、柔和外侧端点与延伸右腿，无角标。界面内以 [`BrandMark`](../pwa/src/components/pwa/brand-mark.tsx)（`currentColor`）绘制。favicon（`icon.svg`）为雾蓝 `#446396` 圆角底加白色标识；安装图标（`app-icon-192/512.png`，同时用于 `any` 与 `maskable`）和 `apple-touch-icon.png` 为满版雾蓝底，标识位于中央 80% 安全区内；`logo.svg` 为透明底雾蓝单色标识；界面内侧栏与启动页的 `BrandMark` 用 `ink`。这些文件由 `pwa/scripts/render-brand-icons.mjs` 生成。独立「Pi Reach」字标见 [`branding/wordmark.svg`](../branding/wordmark.svg)，复用相同的「桥」几何与系统字体；根 README 使用当前 `pwa/public/logo.svg`，历史黑底蓝点 Logo 不再作为现行入口。浏览器主题色跟随 `bg`（浅色 `#FFFFFF`、深色 `#1E1E1E`）；`index.html`、`manifest.webmanifest` 与 [`pwa-appearance`](../pwa/src/components/pwa/pwa-appearance.tsx) 中的同值字面量由 [`pwa-theme-contrast`](../pwa/src/app/pwa-theme-contrast.node.test.ts) 校验与 token 一致。

## 界面语言

界面提供简体中文与英文。设置中的「语言」有「跟随浏览器」（默认）、「中文」、「English」三项；手动选择保存在当前浏览器的 `pi-reach-language`，选回「跟随浏览器」即清除。跟随浏览器时按 `navigator.languages` 顺序取第一个中文或英文条目，任何中文区域都显示简体中文，其余显示英文；浏览器语言变化时随之更新。切换立即生效、不刷新页面，同步 `<html lang>`（`zh-CN`／`en`），时间与数字按界面语言格式化，进行中的连接、发送与配对不受影响。

文案集中在 [`lib/i18n/messages`](../pwa/src/lib/i18n/messages/en.ts)：`zh.ts` 由类型约束与 `en.ts` 结构一致，测试校验每一项都有中文。组件通过 `useI18n()` 取文案，切换语言后重新渲染；非组件代码用 `getMessages()` 按调用时的语言取值。错误与反馈沿用英文原文作为内部标识，经 `safeFeedbackMessage` 白名单过滤后，展示时由 `localizeFeedback` 换成当前语言。只翻译应用自有文案（操作、状态、错误和可访问名称），不翻译用户或 Pi 的消息、电脑与用户自定会话名称、历史原文、路径和命令；扩展写入的默认名 `Untitled session` 视为未命名，按当前语言显示「未命名会话」／「Untitled session」。DOM 查询不得依赖可访问名称文本，改用类名或 `data-*` 属性。

## 布局与导航

布局为「导航常驻」。视口宽度 ≥ 768px 为桌面：不设全局顶栏，应用底色为 `panel`；侧栏宽 260px、贯通全高、贴边，与主区之间不加分割线；侧栏展开时主区是内嵌卡片（`bg` 底、圆角 12，不加阴影和边框），上、右、下与窗口边缘相距 8px，遇到安全区时取两者较大值（见 [ADR-20261010](adr/20261010-desktop-inset-main.md)）；侧栏收起后主区贴满窗口，四边不留间距、圆角为 0（见 [ADR-20261011](adr/20261011-collapsed-sidebar-flush-main.md)）。主屏 PWA（如 iPad）的状态栏按「状态栏与顶部区域」处理，品牌行与收展入口同样避让。侧栏自上而下为品牌行（`BrandMark` 与「Pi Reach」）、电脑选择入口、「在线 Pi」与「本地历史」两个分组（共用一个滚动区），底部固定「配对电脑」与「设置」两个文字按钮。只配对一台电脑时，电脑选择入口收成无框的一行（在线圆点、电脑名与展开箭头，高 44px），多台时为带图标与「当前电脑」副标题的卡片。电脑列表、配对、重命名和删除配对集中在电脑选择面板：桌面为 Popover，移动端为底部 Drawer。未配对时侧栏只显示电脑选择入口（「未配对电脑」）与底部入口。

侧栏可以完全收起，状态保存在当前浏览器的 `pi-reach-sidebar-collapsed` 中。收展入口是成对的左右箭头（`ChevronLeft`／`ChevronRight`），无常态外框：展开时位于侧栏品牌行右端，收起后停在主区标题区左端（距窗口左缘 8px，与品牌行同高），与标题同一行（标题区左侧留白 `56px`），不与导航列表重叠（见 [ADR-20260929](adr/20260929-sidebar-toggle-placement.md)）。侧栏以 220ms 标准曲线收展，主区外边距、圆角、主区内部安全区与收展入口的位置同步过渡（外边距与内部安全区此消彼长，内容不跳动）；收起时主区贴满窗口，阅读列与输入区随之重新居中；收起的侧栏以 inert 隔离焦点，不卸载导航内容。

主区顶部是 48px 的会话标题区（侧栏展开时标题区位于卡片内，比未避让状态栏的侧栏品牌行低 8px）：左侧为「工作目录最后一级 · 会话名」（目录用 `secondary`），本地历史与在线会话格式相同，不另标只读；右侧依次为连接状态、刷新和会话「信息」。未打开会话时只保留状态与操作。连接提示条与错误提示位于标题区下方，与阅读列同宽；Toast 为标题区下方居中的浮层（见「反馈呈现」）。消息阅读列与输入区最大宽度都是 680px，左右留白桌面 20、移动 16px；操作状态并入输入区提示行（与卡片间距 8px），压缩状态在消息末尾单独成行。

视口宽度 < 768px 为移动布局：主区单栏，会话标题区即顶栏，不显示 Logo；顶栏、导航与全屏叠层的状态栏避让见「状态栏与顶部区域」；没有配对或未选中电脑时，顶栏标题为「Pi Reach」，已选中电脑但未打开会话时为电脑名。菜单图标与当前会话名共同构成导航入口，悬停和聚焦只在图标周围显示圆形反馈，入口保持 44px 点击高度；右侧为连接状态与会话「信息」，不显示刷新；已连接时连接状态只显示圆点（文字仅供读屏），其他状态照常显示文字。导航为左侧 Drawer，宽 `min(320px, 85vw)`，四角为直角，进出按「基础层」的 Drawer 动效，顶部为品牌与关闭按钮，内容与桌面侧栏一致，遮罩使用 `scrim`；移动导航不继承桌面收起状态。进入配对／重命名前先完成导航退出；选择其他电脑、Pi 或历史时，主区消息列表以同一时长与曲线随导航退出淡出，在抽屉移动结束（`--pwa-duration-drawer`）时切换、不等退出回调（回调常晚到约 100ms，会在主区留下空白），焦点仍在退出完成后恢复；切换在同一次提交中换上新内容，没有真正切换（关闭被拒、回弹或需要确认）时恢复原内容；进入设置时导航不先播放关闭动画（见「设置页」）；删除配对确认保留底层导航。所有叠层 Portal 到 `.pwa-root`（移动导航挂在工作区视图内，设置页转场时随工作区保持原位、被设置层覆盖），Escape 只关闭当前最上层，关闭后恢复有效焦点。

### 状态栏与顶部区域

主屏 PWA 的页面不延伸到状态栏下方：viewport 不设 `viewport-fit=cover`，状态栏由系统按「状态栏背景条」的颜色铺成实色，不按页面切换状态栏样式（见 [ADR-20261028](adr/20261028-ios-solid-status-bar.md)）。状态栏与左右安全区的避让规则仍保留，在系统报告安全区的环境中生效。所有贴着屏幕顶边的顶栏使用同一规格，不按页面各定一套：移动会话标题区、侧栏收起时的桌面会话标题区、桌面侧栏品牌行、移动导航头部、工具与文件阅读器顶栏、移动设置页顶栏。侧栏展开时桌面会话标题区位于主区卡片内，不贴屏幕顶边：卡片上边距取 `max(8px, 状态栏安全区)`，标题区本身固定 48px，尺寸、左右内边距与标题规格仍同顶栏。

- **尺寸**：高 `--pwa-topbar-height`（48px，44px 按钮上下各留 2px），安全区 `--pwa-safe-top` 叠加在上内边距，不压缩顶栏；标题与 44px 图标按钮在顶栏内垂直居中、处于同一条中线，不另加上下留白。顶栏只放单行内容，完整命令等长内容放进正文。
- **左右内边距**：以图标按钮开头时距边缘 4px，按钮与标题相距 4px（移动标题区、移动设置页、移动阅读器）；以文字开头时取 `--pwa-gutter`（桌面 20px；桌面标题区与阅读器）；导航品牌与下方列表左缘对齐（16px）。右侧图标按钮距边缘移动端 4px、桌面 8px。
- **标题**：统一 `--pwa-text-title`（18px）加粗，单行，过长时省略；标题左对齐，紧随左侧按钮或从左边距开始，不水平居中。桌面设置页不设顶栏，标题为 24px（见「设置页」）。
- **返回与关闭**：移动端全屏页面与阅读器在左侧放返回箭头（与右滑关闭方向一致）；桌面右侧 Drawer 在右上角放关闭。
- **底色**：顶栏与所在图层同底色。主界面与设置页为 `bg`，桌面侧栏、桌面主区卡片上方与移动导航为 `panel`，工具与文件阅读器也为 `bg`（与主界面同色，桌面 Drawer 靠阴影与遮罩和主区分开）；主屏 PWA 的状态栏由背景条取最上层顶栏的颜色，叠层遮罩 `scrim` 不覆盖状态栏。
- **滚动**：可滚动内容不得进入状态栏区域。顶栏固定在滚动区之外或以 sticky 吸附；桌面设置页没有顶栏，在滚动区顶部吸附一条高 `--pwa-safe-top`、与页面同底色的遮挡条，不占布局高度。
- **主题色**：`theme-color` 在运行时跟随外观取 `bg`（浅色 `#FFFFFF`、深色 `#1E1E1E`），不随页面或叠层变化。浏览器标签页和不支持透明状态栏的平台（如 Android 主屏）在打开阅读器等叠层时，状态栏颜色可能与叠层顶栏不同。
- **应用高度**：iOS 在该模式下会把 fixed 定位的初始包含块缩短一个状态栏高度，独立窗口因此以 `100lvh` 作为应用高度，Drawer 与 Modal 相对 `.pwa-root` 定位，导航、遮罩和底部面板铺到屏幕底边。
- **状态栏背景条**：iOS 27 主屏 PWA 在页面顶边中点下方约 4px 处命中检测：命中元素或其祖先是 fixed 时，按其背景色把状态栏铺成实色；否则在状态栏下方加一段向下延伸的模糊，盖住顶栏。实色只在页面不延伸到状态栏下方时出现。伪元素命中后按宿主元素处理，不能用于取色。应用壳因此放一个 fixed 真实元素：满宽，高 12px（iOS 只在盒高超过 10px 时直接读背景色），位于所有叠层之上（见「叠层」中的 `status-backdrop`）；背景只裁到零高的内容盒，不绘制、不接收点击，只供 iOS 取色。颜色与状态栏下方的顶栏一致：移动端、侧栏收起与设置页为 `bg`，桌面侧栏展开与移动导航打开时为 `panel`；Modal 等遮罩不改变颜色。浏览器标签页不生成该元素。
- 新增的顶栏复用 `.pwa-topbar` 与 `--pwa-topbar-height`，并补充状态栏避让的浏览器测试；底部面板（如电脑选择 Drawer）和居中 Modal 的头部不贴屏幕顶边，不属于顶栏。

### 左右安全区

横屏刘海与圆角的左右安全区以 `--pwa-safe-left`／`--pwa-safe-right` 表示（无安全区时为 0，桌面浏览器外观不变）。宽度 ≥ 768px 的横屏手机进入桌面布局，同样适用。原则：安全区只由实际贴住该屏幕边缘的布局层负责，同一边只算一次；贴边层的背景延伸进安全区、内容内缩，子层不再叠加；不贴边的居中叠层与屏幕边缘的距离取 `max(基础留白, 安全区)`，不相加。侧栏 260、阅读器 720、移动导航 320 都是内容宽度，不含安全区；设置页 640 与阅读列 680 位于已扣除安全区的区域内。

| 布局层 | 口径 |
| --- | --- |
| 桌面侧栏（展开） | 面板总宽 260＋左安全区，安全区内为 `panel` 底；收展入口随之右移 |

### 移动端滑动

移动布局支持单指滑动，面板在拖动过程中实时跟随手指；松手后达到识别阈值才提交，复用已有按钮的打开、关闭或返回入口，不改变 history 和焦点规则，未达阈值或反向甩回则回弹。无法跟手时（减少动态效果、起点落在边缘排除区、收尾期间再次按下）退回触发式：松手一次判定，不移动面板。阈值以 [`swipe-gesture.ts`](../pwa/src/components/pwa/swipe-gesture.ts) 的具名常量为准，不在文档中重复维护。桌面宽度、鼠标和触控板不启用。

| 表面 | 手势 | 启用条件 |
| --- | --- | --- |
| 工作区主区 | 右滑打开移动导航；关闭后焦点回到标题区导航入口 | 设置页未打开且无页面转场，导航未打开 |
| 移动导航 | 左滑关闭 | 导航已打开，电脑选择面板未打开 |
| 设置页 | 右滑按原来源返回工作区或展开的导航 | 设置页已打开且无页面转场 |
| 工具详情阅读器 | 右滑关闭 | 已打开且为移动全屏 |
| 文件阅读器 | 右滑关闭 | 已打开且为移动全屏，仍服从原模态关闭门禁 |

按下与提交前都检查阻断叠层：当前表面自身所在 Drawer 之外，可见的 dialog（包括非模态会话信息）、menu 或 listbox 均阻止触发；退出期间带 `inert` 或 `aria-hidden="true"` 的叠层不阻断。输入控件、可编辑内容、整个 Composer、`data-swipe-ignore` 区域、有文字选区或起点祖先中真正可横向滚动的区域均不识别。第二触点、取消事件、表面禁用或卸载会取消本次滑动；按钮、键盘、Escape、遮罩和系统返回继续可用。

移动端需在手势表面及其纵向滚动容器设置 `touch-action: pan-y`，不能只设置最外层。嵌套代码块、表格和 diff 横向滚动区保持默认 `auto`；图片舞台显式退出滑动关闭，保留 `touch-action: none` 的拖动和缩放。文件 Markdown 的围栏代码块与表格一样在块内横向滚动，不撑宽正文，因此从正文其他位置起手仍可右滑返回；若其他内容仍使正文自身横向溢出，整个正文滚动区动态保留 `auto` 并排除滑动关闭，不为手势改变内容换行。以后新增滚动容器须核对最近滚动容器的 touch-action。

手势不限定屏幕边缘：主区中部也可右滑。浏览器或系统占用的边缘返回继续交给既有 history 流程；桌面 Chromium 的移动视口和 CDP 不能代替 iOS／Android 真机验收。

跟手拖动用暂停的 WAAPI 动画随手指移动，拖动期间不改 React 状态；面板位移自方向锁定那一帧起算，反向不越过起点。松手后从当前位置按标准曲线走到终点或起点，时长随剩余位移与松手速度缩短，不长于 `--pwa-duration-drawer`／`--pwa-duration-page`。拖动与收尾期间对目标元素关闭 CSS 过渡（`data-swipe-drag-active`），否则 Mantine 的退出过渡会盖过脚本动画。

| 表面 | 跟随的元素 | 提交与取消 |
| --- | --- | --- |
| 工具／文件阅读器、移动导航关闭 | Drawer 内容与遮罩 | 走到终点后调用一次原关闭入口，退出时长为 0；入口被门禁拒绝（上层确认框等）时回弹，不改 history，之后按钮关闭仍有完整退出动画 |
| 设置页返回 | 设置层与页面遮罩（工作区层保持原位） | 松手即调用原返回入口，路由变化后由页面转场从当前位置续播；1 秒内路由未变则恢复设置页。来源为导航时拖动开始即预挂载展开的导航，工作区仍 `inert`，不启用焦点陷阱，提交后焦点落在导航内的「设置」；回弹则撤销预览与待处理焦点请求 |
| 移动导航打开 | Drawer 内容与遮罩 | 开始时同步挂载并打开导航，期间无焦点陷阱与滚动锁，焦点不动；提交后启用并按现有规则聚焦，回弹后即时关闭且不回焦 |

拖动或收尾中表面被外部关闭（Escape、`popstate`、按钮）时不回弹，从当前位置走到关闭终点，且不再调用关闭入口；取消事件不代表表面状态，仍打开才回弹。导航打开手势被外部关闭后作废，同一次松手不会重新打开。向右拖动的起点落在左缘 24px 内且不是 standalone 时不跟手，避免与浏览器后退手势同时移动；standalone 没有系统边缘返回，不排除（待真机核对）。减少动态效果时位移为 0，不启用跟手。

### 设置页

设置是独立页面，地址为 `/app/settings`，桌面与移动一致，不保留工作区侧栏。页面以 `bg` 为底、内容最大宽 640，自上而下为返回入口、页面标题「设置」与七个分区：外观、字体大小、语言、键盘、连接（Relay 地址与主操作「保存设置」）、浏览器数据（「重置布局」与危险入口「清除本地数据」）、关于，分区间距 32。键盘分区提供「Enter 发送消息」开关与「键盘快捷键」帮助入口，发送偏好立即生效并保存在当前浏览器；具体行为见[桌面键盘](#桌面键盘)。字体大小提供标准、大、特大三档，选择后立即应用并保存在当前浏览器；只放大字号，不改变间距、图标与点击区。外观、字体大小与语言为单选卡片：`surface` 底、未选中不描边，选中时边框改为 `ink`，只有选中的单选圆点用 `accent`，未选中的圆点轮廓用 `control-line`；边框保留 1px 宽度并取透明，不用取消边框改变尺寸。桌面返回为带文字的按钮（「返回工作区」），标题 24px 在其下方；移动端返回箭头（44px，与其他图标按钮同为 `secondary`、悬停为 `ink`，可访问名称随来源为「返回导航」或「返回工作区」）与 18px 标题同一行，组成固定顶栏；桌面不设顶栏，滚动时由状态栏遮挡条避让（均见「状态栏与顶部区域」）。保存后留在设置页并以 Toast 提示「设置已保存」。

「关于」以左侧名称、右侧版本的三行列表显示 PWA、Relay 与扩展版本，下方注明当前电脑与 Pi；没有选中在线 Pi（包括阅读本地历史）时不显示对象说明。连接或握手期间显示「正在获取版本…」，离线显示「未连接」，没有当前在线 Pi 时扩展显示「未选择在线 Pi」。版本信息不按三端数字是否相同判断兼容性。标题右侧提供「复制版本信息」图标按钮，复用现有复制反馈，只复制版本与必要状态，不包含 Relay URL、电脑名、会话名、路径或身份信息。

进入时 `pushState` 一条记录，state 保存来源（工作区，或已展开的移动导航及其滚动位置）；页内返回与浏览器／系统后退都回到上一条记录并按来源恢复：回到工作区时保留会话、草稿与阅读位置，焦点回到侧栏的「设置」；回到移动导航时导航以展开态直接呈现并恢复滚动位置，焦点落在导航内的「设置」。直接打开或刷新 `/app/settings` 停留在设置页，并在其下补一条工作区记录，返回后再后退不会回到设置页；浏览器前进重新进入时照常播放进入转场；系统已为本次历史导航提供原生视觉转场（`hasUAVisualTransition`，如 iOS 边缘手势）时不再叠加应用转场，直接呈现目标视图；未识别的 `/app/*` 显示默认工作区并把地址改回 `/app`。进入后焦点落在页面标题（可程序聚焦、不在 Tab 顺序中），标签页标题改为「设置 · Pi Reach」，返回后恢复；直接打开时不移动焦点。移动布局的右滑返回与页内返回共用入口，启用和排除规则见[移动端滑动](#移动端滑动)。清除本地数据后重新载入工作区。

转场与右侧 Drawer 同一覆盖模型，200ms（标准曲线）：进入时工作区保持原位，设置页带 `--pwa-shadow-modal` 从右滑入并覆盖，整个过程保持直角（静止后去掉阴影），其下的 `scrim` 遮罩同步淡入；返回时反向；中途反向或由跟手拖动交接时从设置层与遮罩的当前状态继续。遮罩只在转场与拖动期间可见，不拦截点击。从导航进入时，导航随工作区保持原位、被设置页覆盖，滑入完成后直接卸载，不播放关闭动画。减少动态效果时改为交叉淡化。

桌面与移动端的会话「信息」是非模态的只读信息弹层：完整会话名（换行不截断）、工作目录完整路径（等宽、无框的原生只读文本字段）、电脑名 · 状态。触发器与弹层的可访问名称均为「会话信息」，弹层采用 `dialog` 语义，打开时焦点进入信息区；Tab 可进入路径字段，使用系统全选与复制快捷键，Escape 关闭后回到触发器；点击外部关闭时不抢走外部控件的有效焦点。路径字号跟随字号档位且不低于 16px，避免移动浏览器聚焦输入时缩放。没有目录时信息区仍可聚焦。在线会话、已退出的 Pi 与本地历史均不在此提供命令或连接重试操作；新会话、压缩上下文、模型与思考级别从输入区进入。会话名在导航与顶栏中单行截断，悬停以 `title` 显示全名。

## 组件规则

- **电脑与活动 Pi**：电脑是持久 pairing；活动 Pi 仅来自当前 Relay snapshot，列表名称使用当前 Pi 会话名称，重命名及切换会话后同步更新。状态徽标同时给出文字和图形状态，不能把缓存 metadata 画成在线。
- **在线 Pi 行**：与历史条目同为最小高 44、左右内边距 8、行间 2 的导航行；纯细指针且可悬停时上下内边距 4，存在任一粗指针或不可悬停时为 6，双行内容自然撑高，文字与品牌、分组标题同一左缘（距侧栏 16）。第一行为会话名（未命名为「未命名会话」），第二行为工作目录最后一级 · 运行中（运行色＋动态图形）或空闲；不显示模型名。当前项为 `selected`＋`ink`，悬停时保持不变，以 `aria-current` 标记并保持可聚焦。非当前查看的 Pi 由运行中变为空闲时，行右侧显示直径 6px 的 `accent` 圆点（读屏为「有新回复」），移动端菜单图标右上角同样显示；打开该会话后消失，只保存在页面内存中。等待 Relay 快照时分组内显示骨架行，没有在线 Pi 时只有一行「没有在线的 Pi」。
- **历史条目**：历史是 PWA IndexedDB 中已保存的正式 timeline scope，而不是远程 Pi session 列表，只列当前电脑的记录。第一行为已保存的会话名，缺失时回退到纯文本消息预览（仅清理常见 Markdown 标记、保留链接文字）；第二行只有时间：今天显示时刻，昨天显示「昨天」，更早显示日期。直接列出当前电脑的全部记录，不分批展开。在线 Pi 的当前会话只出现在「在线 Pi」分组，本地历史不重复列出：当前选中的 Pi 隐藏已握手的实时会话，其他在线 Pi 隐藏它在本浏览器中最近更新的一条记录；Pi 退出或切换会话后，这些记录回到本地历史，正在阅读的历史始终保留。某个 Pi 在未被查看时切换了会话，它的上一段会话会暂时隐藏，直到打开该 Pi 或它退出。打开历史后输入区保持在线会话的结构与样式但全部禁用（见「实时与只读历史」）；点击在线 Pi 即退出历史。
- **会话正文**：用户、Pi 回复、思考与独立工具行保持事件顺序；扩展 `custom` 事件暂不渲染原始 payload，压缩与分支摘要仍显示。不用头像，也不逐条标发送方或时间：用户消息靠右、`message` 轻底，Pi 回复靠左占满阅读列、无底色，每条前有仅读屏可见的「你：」「Pi：」。一轮回复（同一 `group_id`）连续排列；只有收到本轮正式 `run_end` 后才在末尾显示一次完成时间（13px／`secondary`），中断或出错时附状态文字，进行中不显示。在线会话有可见时间线内容、Pi 处于 `working`，且最后一轮尚未收到 `run_end` 时，采用「具体状态优先、Working 兜底」：当前轮的思考行或工具组已有可见运行旋转提示时，不重复显示「Working…」；没有具体运行提示时，在末尾立即显示旋转图标，文字以 `--pwa-duration-fade`（120ms）淡入「Working…」，不延迟业务状态、不增加位移动画。正文流式输出没有独立运行图标，仍显示 Working；工具已经完成、只保留摘要或完成状态时，若 Pi 仍在工作则显示 Working。工具组只要仍有运行中的调用，组头就在固定位置显示整组旋转提示，轮播暂时停在已完成调用时也不新增 Working；展开列表中各调用仍显示自身真实状态。具体图标被隐藏、裁剪或不属于当前轮时，仍由 Working 即时兜底。最后一轮收到 `run_end`、Pi 变为空闲或连接离线后隐藏；提示的隐藏不替代正式 `run_end`，也不确认本轮结束。结束判断只按末轮，已结束或较早轮次残留的 partial 不改变当前轮的判断。待发送消息只显示普通气泡，不显示「发送中」或成功提示；无法确定投递时在气泡下方显示「尚未确认」与核对图标，明确失败时显示短原因，可重试的附「重试发送」图标；排队项留在排队区，插入未确认与取消沿用既有状态。原目标失效（Pi 重启、会话替换或 Owner 变化）的未确认内容只读保留并说明「原目标已不可用」，只在原 Pi 下显示，不提供核对或重试；已确认取消但附件无法放回输入区时保留内容并说明，断线重连不改回「尚未确认」。模型错误以错误色图标＋文字行呈现。
- **发送消息与跟随**：本端新消息成功提交发送后立即恢复后续回复跟随，文字与附件消息一致；附件开始上传不提前改变阅读位置；未接管失败保留草稿与原阅读位置，已接管后的 transport 失败由原消息承担并清空输入区。成功提交时保留当前可见几何，以 `--pwa-duration-message-in`（160ms）和标准曲线在同一时钟内协调输入区回缩与滚动贴底，立即开始、约 160ms 内到达底部，不先瞬时跳到底部再播放过渡；附件最终提交移除卡片时，输入区总高度也在本次短期过渡内收回，结束后不留占位。过渡中的回执、Working 与回复增量从当前显示位置更新目标，不重启时钟。结束时先恢复自然布局再读取真实终点，程序滚动交接不误显示「最新」。Working 的实际显隐独立通知视口；没有发送过渡时，优先使用消息区现有底部留白，保留至少 8px 基础间距，空间足够则已稳定的正文不再移动，空间不足才以同一 160ms 标准曲线补足必要位移。跟随不要求每次补齐整段底部留白；后续正文与回执接续当前有效目标，不在下一次提交时补回已使用的留白，也不因此误显示「最新」。状态移除或与思考／工具替换按净布局处理，原位置仍可达时保持不动；短屏收缩使原位置不可达时，仅在短期交接内保留尚未收回的空间，平滑收口后完全释放，不留下永久占位。回看时仍保持阅读锚点，同高度状态替换不额外启动滚动，普通回执与正文增量不创建新过渡。用户再次上滑立即取消跟随并保留阅读位置，切换会话、展开详情或卸载时释放旧过渡，下一条草稿输入重新交还普通高度测量。普通异步输出不抢阅读位置，点击「最新」沿用原有恢复规则。仅在线新发送气泡以同一时长和进入曲线从下方 6px 上移并淡入；位移裁剪在气泡自身的静态框内，不给整个列表添加位移或高度动画。回执与正式记录交接保留同一气泡，不重播动画；初次加载的历史或待发送记录、重试及流式更新均不播放。减少动态效果时输入区和贴底即时完成，气泡只淡入（时长见[「动效」](#动效)）。普通发送不渲染尾部投递状态，也不借用底部留白；只有失败、未知和排队等异常行按正常文档流排布，不遮挡内容或缩小操作区，确认后不因异常消失而回弹。
- **Markdown**：标题分两级（`#`／`##` 18px、其余 16px，均 600），段落 16px／1.65；链接 `accent` 常显下划线并在新标签页打开；行内代码 `panel`＋`soft-ink`；引用左侧 2px `control-line` 竖线；宽表格自身横向滚动。代码块使用 `code-surface`、圆角 8，按围栏语言以 highlight.js 高亮（超出大小上限时不高亮）；顶部为高 36px 的标题栏，左侧为围栏语言名（等宽 13px、`code-dim`，无语言时留空），右侧为复制按钮（点击区 44px，上下以透明扩展区越出标题栏）；标题栏下方的代码区只负责横向滚动，长行不会滚到按钮下方。
- **思考与工具行**：状态行无分割线，行间距 6px；Working、折叠思考与工具组头使用同样的 44px 最小高度和上下各 6px 外边距，替换提示不额外改变列表高度。压缩进行中在同一位置显示「Compacting context…」；失败、取消与待确认作为本地提示行停在发生时的最后一条记录之后，不写入会话，成功压缩或切换会话时随聊天区重建消失。Working 为 16px／600、运行色，但不使用斜体；思考标题同为 16px／600、斜体、`secondary`，运行状态由左侧旋转图标表达。同一轮中展示相邻的工具从第一条起组成工具组，不论条数与状态（运行中、成功、失败、中断、未知），不等待 `run_end`；夹有正文、思考、已发布文件或未保存缺口时断开（见 [ADR-20261011](adr/20261011-live-tool-grouping.md)）。工具组默认收起，展开与否只由用户决定，执行状态不自动展开或收起。组头不显示“工具调用”之类的说明：折叠时按开始顺序排队显示在线期间新出现的工具，左侧为工具名＋命令／路径（16px，单行省略），状态图标统一放在右侧、折叠箭头之前，每条都显示一次，换下一条时只有文字自下而上进入一次（减少动态效果时只淡入）；右侧状态使用固定 - **主区空状态与加载**：位于阅读列中部偏上，自上而下为 24px Lucide 图标（`secondary`）、标题（18px／600）、一行说明，最多一个操作，不用插画。间距只由各元素的上外边距负责：图标到标题 16、标题到说明 8，说明到命令块、操作或列表 16。启动失败页为最大宽 520 的卡片（`surface`、1px `line`、圆角 12），内边距桌面 32、移动上下 24 左右 16，状态图标块 48×48 内含 24 图标。未配对显示「还没有配对的电脑」、一句说明「在电脑上的 Pi 中运行下面的命令。」、单独一行的 `/pi-reach pair` 命令块（`panel` 底、高 44px、右侧复制按钮）与主操作「开始配对」；已配对无在线 Pi 显示「没有在线的 Pi」，有本地历史时附文字按钮「查看本地历史」；多个在线 Pi 且没有可沿用的选择时，主区标题为「有 N 个在线的 Pi」，下方以有边框的可点行列出（`surface` 底、1px `line`、圆角 8、最小高 56，运行中的排在前面，右侧箭头）；新会话无消息时显示「向 Pi 发送消息开始。」，下方一行 13px 小字为「目录 · 模型 · 思考级别」（缺项省略），桌面首次进入空会话时聚焦输入框，移动端不自动弹出键盘。等待快照或打开会话时使用 `hover` 色骨架屏：300ms 内完成不显示，出现后至少 500ms，约 2 秒的轻微明暗呼吸，减少动态效果时静止；打开会话时骨架行显示在消息列表内，列表保持挂载。
- **反馈与错误**：按来源与生命周期选择连接 banner、Toast、局部错误或持久提示，具体规则见下文。低频状态使用 live region，提示不能遮挡 Composer 或主动夺取焦点。
- **表单与叠层**：配对、重命名、清除数据等操作保留明确取消路径。叠层的上下顺序与取值见[「叠层」](#叠层)。遮罩始终只有一层：Modal 叠在带遮罩的 Drawer 上时下层遮罩隐去。居中 Modal 统一轻量进出：遮罩淡入、弹窗上移 `--pwa-overlay-shift`（8px）并淡入，进入 180ms（进入曲线）、退出 140ms（退出曲线），退出期间不接收指针，关闭开始时焦点即回到来源控件；减少动态效果时只淡化。宽度确认类 400、表单类（配对、重命名）与快捷键 480，只由 Mantine `size` 决定：主题默认 480，确认弹窗单独指定 400，CSS 不写弹窗宽度；移动端两侧各留 `max(16px, 左右安全区)`。底部操作区按钮间隔 8；对齐的操作组使用最小宽：确认弹窗 120、重命名弹窗 88，单独出现的页面按钮不加最小宽。移动端确认弹窗按钮纵向全宽，重命名弹窗两按钮等分。关闭顺序、焦点和 Escape 竞争按组件测试契约验证。

### Mantine 复用边界

基础控件直接使用 Mantine，公共默认尺寸、variant 和产品 class 由 [`piReachTheme`](../pwa/src/lib/ui/pi-reach-theme.ts) 注入；业务 CSS 保留视觉 token、响应式和领域状态样式。原 `components/ui` 薄包装已移除，不为统一导入路径重新封装组件库 API。`ActionIcon` 保持 44px 触控目标；危险入口使用 `outline` 变体，确认弹窗中的危险确认使用 `filled` 加 `pwa-danger-confirm`，颜色都由 CSS token 决定，不传 `color` prop（见[「按钮尺寸」](#按钮尺寸)）。

- **导航项**：电脑选择面板、Online Pi 和历史条目使用 `NavLink`，明确指定按钮语义。当前电脑和离线电脑仍可选择；当前活动 Pi、当前历史项及 snapshot 未就绪时的门禁沿用业务规则。电脑操作菜单是选择按钮的兄弟控件，不能嵌套按钮。
- **菜单与弹窗**：Menu 与 Popover 容器内边距 6；菜单项完整命中区最小高 44、左右内边距 10、图标与文字间隔 8、圆角 8。命令与模型列表的上下内边距在纯细指针且可悬停时为 4，触控／混合输入为 6；细指针单行的视觉底可内缩至 40px，命中区仍为 44px 且不重叠，双行及完整长名称按内容撑高。当前项 `selected`＋`ink`；禁用项改为 `secondary` 文字，不靠透明度（发送／停止按钮的透明度禁用态除外）。附件、命令、模型与电脑动作菜单按实际定位方向轻移 `--pwa-menu-offset`（4px）并淡化，进入 160ms、退出 120ms（`--pwa-duration-menu-in/out`）；不缩放整个菜单以免压缩命中区，减少动态效果时只淡化（见[「动效」](#动效)），已挂载菜单也即时响应系统偏好。会话信息弹层是只读信息区，保留 8／10 的阅读内边距。命令菜单使用 `Menu`；会话「信息」使用 `Popover`，以非模态 `dialog` 语义展示只读信息，不提供操作菜单项。配对、重命名与确认使用 `Modal`，统一进出与遮罩由 [`piReachTheme`](../pwa/src/lib/ui/pi-reach-theme.ts) 的 Modal 默认值提供；配对码使用 `TextInput`。命令菜单先关闭再执行需要交接焦点的业务动作，保留原有二级视图、取消和回焦规则。
- **空状态与加载**：主区空状态与骨架屏由 `workspace-content.tsx` 的业务组件实现，延迟显示逻辑为 `useDelayedVisibility`。配对等待使用 `Loader`；停止任务和工具状态图标继续表达各自业务语义，不统一替换。
- **文件选择**：普通附件使用 `FileButton`。由菜单触发的文件 input 在菜单关闭后仍须挂载；原有清空 input 的入口继续支持重复选择同一文件。摄像头的原生 `capture` input、图片粘贴和资源释放仍由业务组件处理。
- **折叠与滚动**：`ToolCard` 和 `ThinkingContent` 使用业务组件 [`Collapse`](../pwa/src/components/pwa/collapse.tsx)（非 Mantine `Collapse`）：只在用户切换时以 `grid-template-rows` 伸缩，使用独立 `--pwa-duration-collapse-in/out`（180／140ms），折叠箭头采用同样时序；已展开内容的流式增长不重播动画；退出期间 `inert` 并冻结为收起时的内容，透明度退出完成后卸载（按实际退出 token＋50ms 兜底，系统偏好变化时重算），中途反向从当前位置继续。复制按钮统一使用 `CopyButton`。业务布局和原生滚动容器继续承担历史 prepend、流式跟随及触摸行为，不默认改用 `AppShell` 或 `ScrollArea`。

## 实时与只读历史

活动 endpoint 选择和历史阅读是两个模式。对活动电脑，PWA 在 Relay snapshot 后处理 0/1/N：0 个在线 Pi 显示空状态，1 个可以自动选中，N 个在主区列出供选择（仍保留用户明确选择）。有新的 Pi 上线时不自动切换，只在列表中新增；处于「没有在线的 Pi」时有 Pi 上线即自动进入。用户正在阅读历史时，自动 endpoint 选择暂停，实时更新不得抢走历史视图。

正在查看的 Pi 退出后，会话内容保留在原位，标题区状态变为中性色「已退出」，输入区位置换为说明「这个 Pi 已退出，会话记录已保存在本地历史。」，有其他在线 Pi 时附「选择其他 Pi」；此时同样暂停自动选择，同一目录再启动的 Pi 按新实例处理；同一实例（runtime 不变）因 Relay 重启等短暂缺席后重新上线时，不算退出，恢复实时会话。同一 Pi 进程切换到新会话（如 `/new`）时主区跟随新会话，并在开头以一行居中的 `secondary` 小字标出「Pi 已切换到新会话」。

同一电脑上切换到另一个 Pi 时，旧会话随标题一起立即撤下，不留在新 Pi 的标题下。本浏览器保存过该 Pi 的会话时（优先本次访问握手过的会话，否则取本地历史中该 Pi 最近更新的一条），先显示其最近的连续记录，握手确认仍是同一会话后只补齐缺口，补齐期间不在顶部显示「正在加载记录」；会话已经变化则撤下这些记录，按首次打开加载。没有可显示的记录时，消息列表内显示骨架屏，直到首批历史到达，期间不显示空会话提示和顶部的更早记录入口。新内容出现时整个消息列表从约 1/3 可见度以 `--pwa-duration-content`（240ms）与标准曲线淡入，不加位移，避免骨架在同一帧卸载后出现完全空白的一帧；标准曲线前段很快，短于此时长时肉眼只看到内容直接出现；减少动态效果时改用统一的短时长（见[「动效」](#动效)）；已有内容的增量更新和空会话里的第一条消息不重播。切换电脑、Pi 或历史时，旧会话先淡出再换上新内容，桌面与移动端一致：移动导航中的选择随抽屉退出淡出（见上文移动布局），桌面侧栏等没有导航退出的入口先以 `--pwa-duration-fade` 与标准曲线淡出再切换；淡出期间改选其他目标时只执行最后一次选择。切换不使用位移转场。

首次打开某个会话（在线 Pi 或本地历史）时停在底部最新内容；同一次访问中切回看过的会话时恢复离开时的阅读位置：离开时在底部则继续跟随最新输出，否则按离开时顶部可见的行重新定位，该行加载出来之前先停在底部，用户主动往上回看则以用户位置为准。展开思考、工具组或打开详情阅读器仅暂停自动跟随，不立刻标记离开底部。「最新」入口与是否跟随分开判断：滚离底部 32px 即结束跟随，但入口只在离底部超过一屏、且触摸、惯性与回弹结束 200ms 后才出现，回到一屏以内立即隐藏；在底部附近回看不出现入口，滑一下即可回到底部。在线会话有未读输出时不受距离限制，直接显示「N 条新输出」。位置只保存在页面内存中，刷新后清除。

在线会话与本地历史共用顶部的更早记录入口，行为一致：阅读位置距列表顶部不超过两屏视口高度与 400px 中的较大者时自动向前加载，避免惯性滚动到顶后才前插；仍跟随最新输出时不自动加载，用户滚离底部后才生效；内容不足一屏时也自动补页并继续跟随最新，补页不再增加高度时停止；用户向前加载的一页若在手指按住、惯性或回弹期间到达，先暂存并继续显示加载中，手指抬起且 200ms 内没有新的滚动后再前插，不与系统滚动争夺位置（否则 iOS 上会出现来回抖动的重影）；前插后保持原阅读行位置，仍被系统覆盖回顶部时，1 秒内没有新的触摸（含拖动）、滚轮、按键或指针输入就重新恢复，不因此连续向前加载。入口与正文同一居中列、最小高 36、下方 12，切换状态时高度不变：空闲保留「加载更多」按钮，供键盘和无法自动触发时使用；加载中按「主区空状态与加载」的延迟规则显示 12px 旋转图标与「正在加载记录…」（`secondary`、13px）；失败后停止自动加载，显示「更早的记录加载失败」与「重试」；在线会话断线时只显示「连接后可加载更早的记录」。

打开历史会关闭当前 session channel，仅从 IndexedDB 读取对应的 `device_id + endpoint_id + session_id + history_generation` 正式 timeline，`MessageList` 使用 `isLive=false`。历史与在线会话使用同一个时间线组件与视口：只读投影不接收实时帧，Relay 断开也不撤下正在阅读的历史；滚离末尾时同样显示「最新」入口。历史视图不提供远程控制或隐式 resume：Composer 保持在线会话的结构与样式，文本框、附件、`/` 命令、模型标签和发送按钮全部禁用，文本框占位为「历史会话不能发送消息」；模型标签显示该会话在线时 Pi 最后报告的模型与思考级别（随会话记录保存，模型或思考级别每次变化时更新，Pi 离线后仍可显示），没有记录时不显示；输入框上方的提示区说明「这是本地保存的历史会话，只读。」。返回在线 endpoint（包括同一个 Pi）时撤下只读投影，重新握手建立实时 session。读取本地记录期间按「主区空状态与加载」显示会话内骨架，不显示「没有可显示的记录。」，读完后内容按切换 Pi 的规则淡入。长历史先渲染最近 30 条，向前每次展开 80 条（与在线会话向前加载的页大小一致；按条数翻页，本地缺口再大也不会出现空页），展开规则同上方更早记录入口；只读历史向前展开不依赖实时连接；附件卡片按整个会话的记录关联，不受分页窗口限制。本地记录按序号缺少开头时，展开到最早一条后在顶部居中显示「更早的记录未保存在此浏览器」；中间缺少的区间在缺口处以同样样式显示「中间有记录未保存在此浏览器」。切回看过的历史时先展开到离开时的范围，再按离开时顶部可见的行恢复阅读位置。

## 桌面键盘

快捷键适用于桌面布局（宽度 ≥ 768px），不改变移动布局的输入行为。`Mod` 在 macOS 显示为 `⌘`，其他平台显示为 `Ctrl`。键位与展示标签由 [`keyboard-shortcuts.ts`](../pwa/src/lib/pwa/keyboard-shortcuts.ts) 统一维护。

- 输入框默认 Enter 发送、Shift + Enter 换行，Mod + Enter 同样发送；在设置中关闭「Enter 发送消息」后，Enter 换行、Mod + Enter 发送。偏好保存在当前浏览器的 `pi-reach-enter-sends`，不随「重置布局」改变。
- 发送复用发送按钮的在线、附件、运行中与并发门禁；Pi 运行中 Enter 仍用于换行，任何发送快捷键都不触发停止。输入法组合输入、已消费的事件、长按重复与额外修饰键不触发发送。
- Mod + `\` 收展侧栏，Mod + `,` 打开设置，Mod + `/` 查看帮助；页面级快捷键在输入控件、可编辑内容、菜单、弹窗或覆盖阅读器打开及页面转场时暂停。设置页只保留帮助快捷键，不操作被覆盖的工作区。
- 设置中的帮助按钮与帮助快捷键共用一个 Modal，Portal 到 `.pwa-root`，键位说明随平台、界面语言与发送偏好更新。Escape 只关闭最上层，帮助关闭后返回有效来源焦点；不为新会话、压缩或停止新增快捷键。

## 可访问性与动态效果

- 键盘焦点始终可见；Drawer/Modal 关闭后回到有效的来源控件或已定义后备控件。
- 异步输出不强制滚动阅读中的用户；“Latest”入口提示未读输出。点击后平滑滚到底部；距底部超过两屏时先瞬时移到离底部一屏处，只平滑最后一屏，避免长距离平滑滚动出现整屏空白帧。
- 系统开启 `prefers-reduced-motion: reduce` 时取消位移、缩放、尺寸过渡与平滑滚动，只保留短淡化，循环暂停；规则见[「动效」](#动效)。
- 移动布局使用 `--pwa-app-height`（浏览器标签页为 `100dvh`，随工具栏伸缩；主屏 PWA 为 `100lvh`，即整屏，避开 iOS 缩短的初始包含块）和 `safe-area-inset` token，Drawer、Composer、对话框及列表必须保持可滚动且不遮挡。
- **软键盘**：完全交给浏览器原生处理，应用不补偿外壳尺寸、不锁文档高度、不复位窗口滚动。viewport 声明 `interactive-widget=resizes-content`，支持的浏览器缩小布局视口，应用壳随 `--pwa-app-height` 缩高；只缩小 visual viewport 的浏览器（如 iOS）由系统把整页上推，使聚焦的输入区位于键盘上方，此时顶栏随页面滑出屏幕、消息区不缩高，收起后由系统复位。贴底与阅读锚点沿用时间线既有的容器尺寸观察，不另设滚动规则。
- **矮窗口密度**：应用壳可见高度 ≤ 600 时为矮窗口、≤ 450 时为极矮窗口（阈值见 [`use-viewport-density.ts`](../pwa/src/lib/pwa/use-viewport-density.ts) 的具名常量），按应用壳实际尺寸判断，布局视口随软键盘缩小时同样生效：只压缩消息区上下留白、提示条与 Toast 的纵向空间，运行时提示条说明改为仅读屏可见；不缩小 44 点击区域、字号、左右边距和安全区，提示条图标保持 16。
- **输入区高度**：文字行高 `1.4`，按视觉行增长，高度充足时最多 6 行后内部滚动；上限由实际布局计算（扣除顶栏、通知、队列、附件与输入区非文字部分），不使用固定视口阈值。空间不足时提前内部滚动，textarea 不低于 44px，消息区至少保留一行正文与上下各 8px 留白；仍无法容纳时标记为布局冲突，不隐藏内容或缩小触控目标。
