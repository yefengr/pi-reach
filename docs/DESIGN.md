# 当前 PWA 设计

本文是 Pi Reach 当前 PWA 的视觉与交互规则真源。规则来自 `pwa/src/app/pwa-theme.css`、`pwa/src/app/globals.css`、`pwa/src/app/workspace-navigation.css`、`pwa/src/app/workspace-shell.css`、`pwa/src/lib/ui/pi-reach-theme.ts` 及现有 PWA 组件；未来原型或主题方案不能覆盖本文。

## 视觉 token

PWA 使用浅色、深色和系统跟随三种外观。页面、表面、选中态与长篇对话都以无彩中性灰（R=G=B）承载；主色为在 Pi Reach「钢雾蓝」基础上提纯的雾蓝，只用于主操作、文字按钮与链接、焦点、单选框选中点和在线／新回复圆点（见 [ADR-20261001](adr/20261001-neutral-surfaces-mist-blue.md)）。token 定义在 [`pwa-theme.css`](../pwa/src/app/pwa-theme.css)：浅色在 `:root`，深色在 `:root[data-mantine-color-scheme="dark"]`；Mantine 在首屏脚本写入属性前，CSS 按系统深色偏好回退到同一组深色值。[`pwa-theme-contrast`](../pwa/src/app/pwa-theme-contrast.node.test.ts) 测试直接读取该文件，校验下文的对比度约束以及深色回退与深色主题一致。

状态色按语义使用，不随组件各自取色：在线与新回复为 `accent` 圆点、文字用中性色；正在执行（运行、连接、重连、思考）用琥珀色加动态图形；成功结果（工具完成、附件就绪、成功通知图标）用绿色；需要关注的情形（附件暂停、插入未确认、主机截断输出、部分在线）用琥珀色加文字或图标；失败与危险用红色；空闲、离线、排队、发送中、已中断、预览缩短与一般说明用 `secondary`。已中断是用户主动停止，不用错误色。例外：标题栏的离线与无网络用中性色，持续断线的提示条可用红色；Toast 保持中性底色与正文，只给图标着色；正常完成时间用 `secondary`；diff 的增删行用完成色与错误色，与执行状态无关。每种状态另有轻底（`*-wash`），实心按钮上的文字用 `--pwa-on-status`（浅色白字、深色 `#1E1E1E`）。状态必须同时有文字或图标，不能只靠颜色。

| 状态 | 浅色文字／轻底 | 深色文字／轻底 |
| --- | --- | --- |
| `complete` | `#347953` / `#EAF3EC` | `#95CBA8` / `#26392E` |
| `running` | `#90611F` / `#F9F2E6` | `#DFBA77` / `#3D3528` |
| `error` | `#AE463E` / `#F8ECEA` | `#EFA39B` / `#422F30` |

危险实心按钮悬停／按下为浅色 `#973B34`／`#82312C`、深色 `#F4B2AC`／`#F8C4BD`。

对比度约束（由测试校验）：`ink`、`secondary` 在全部中性底上 ≥ 4.5:1，`soft-ink` 在主要阅读底上 ≥ 4.5:1；`hover` 对 `bg`／`panel`／`surface` ≥ 1.10:1，`neutral-active` 对 `hover` ≥ 1.08:1，`selected` 对 `panel` ≥ 1.14:1 且不与 `hover` 同值，`disabled-bg` 不与 `hover` 同值；`accent` 在 `bg`／`surface`／`panel`／`hover` 上及 `on-accent` 在三档强调底上 ≥ 4.5:1；`control-line` 对 `bg`／`surface`／`panel` ≥ 3:1；状态文字对各自轻底、`on-status` 对实心状态色 ≥ 4.5:1；代码底上的文字与深色强调色 ≥ 4.5:1。

### 基础层

| 项目 | 规则 |
| --- | --- |
| 字体 | 只用系统字体，不下载网络字体。界面 `--pwa-font-ui`（`-apple-system`、`Segoe UI`、`PingFang SC`、`Microsoft YaHei` 等），代码与路径 `--pwa-font-mono`（`ui-monospace`、`SF Mono`、`Menlo`、`Consolas` 等）。时间与计数使用 `tabular-nums` |
| 字号与行高 | 16px 基准：元数据 13、侧栏列表 14、正文 16、代码 14、会话标题 18、页面标题 24（px），不使用 13px 以下字号；桌面与移动端输入框均为 16px。行高正文 1.65、界面文字 1.4、代码 1.55 |
| 字号语义 | 侧栏列表和表单选项标签为 14px／600；弹窗与配对正文、压缩和分支摘要为 16px／1.65，排队消息正文为单行 16px／1.4；加载说明、运行提示标题、Toast、只读说明、思考标题与操作文字为 16px／1.4；图片省略说明与配对连接状态为 13px／1.4；阅读器命令标题与行内代码为等宽 14px／1.55 |
| 局部尺寸例外 | 不计入间距档位：消息区底部 `88px`（浮动「最新」入口避让）、主区空态顶部 `clamp(48px, 24dvh, 260px)`（上限与侧栏宽度无关）、行内代码／命令胶囊 `1px` 纵向内边距与工具箭头 `1px` 光学对齐；收起侧栏后标题保持主区 gutter |
| 字重 | 只用 400 与 600；600 用于标题、会话名、分组与状态标签、按钮文字 |
| 间距 | `--pwa-space-2xs/xs/sm/md/lg/xl/2xl` 为 4／8／12／16／24／32／48px，按内容关系选用：标题与说明 4；表单标签与输入框、单选卡片之间、相邻独立按钮 8；一般内容到表单主操作 16；弹窗正文到底部操作区桌面 24、移动 16；页面大分区 32；页面底部留白 48。页面 gutter（桌面 20、移动 16）由布局层单独定义，不属于通用档位。同一间隔只由一个布局层负责，父容器用 gap 时子元素不再叠加同方向 margin。不在档位内的间距（导航与菜单的 2／6／10、Composer 的 10、对齐用的负外边距、1px 光学校正等）须在 [`pwa-style-guard`](../pwa/src/app/pwa-style-guard.node.test.ts) 中按文件、选择器与属性登记取值和理由；该 CSS 静态守卫同时要求十六进制色值只出现在 `pwa-theme.css`、边框与轮廓宽度不超过 3px。它只防止 CSS 字面量回退，不覆盖 TSX 中的 Mantine props 与内联样式，也不替代盒模型与行为测试 |
| 圆角 | `--pwa-radius-xs/sm/md/lg` 为 4／6／8／12px：标签与行内代码 4；按钮、输入框、列表行 6；消息、代码块、工具输出、Popover、Menu、Toast 8；输入区、桌面主区卡片、Modal、底部 Drawer 上沿 12；从侧边滑入的面板朝向下层的一侧两角为 12、贴屏幕的一侧为 0（移动导航右侧两角、桌面阅读器 Drawer 左侧两角始终如此；铺满屏幕的设置页与移动全屏阅读器只在进出与跟手拖动时显示左侧圆角，静止时四角为 0，不在角上露出下层界面）；其余贴边整块表面为 0 |
| 阴影 | 页面内元素（侧栏、桌面主区卡片、消息、输入区、设置分区）不用阴影；浮层（Popover、Menu、Toast）用 `--pwa-shadow-float` 加 1px `line` 边框；模态（Modal、Drawer）用 `--pwa-shadow-modal` 加 `scrim`；设置页仅在转场与跟手拖动期间同样使用，静止时不带阴影 |
| 焦点 | 所有控件 2px `accent` 轮廓，贴边绘制（偏移 0）；Mantine 自带焦点环关闭，由全局 `:focus-visible` 统一 |
| 滚动条 | 会话消息区等主滚动区保持系统原生；侧栏、代码块、工具输出、宽表格、命令菜单等内部滚动区为 `scrollbar-width: thin`、`control-line` 颜色，不隐藏滚动条 |
| 断点 | 单一断点 768px：视口宽度 ≥ 768px 为桌面布局，< 768px 为移动布局（CSS 写作 `max-width: 767.98px`，Mantine `sm` = 48em） |
| 动效 | 曲线只用标准 `cubic-bezier(0.2, 0, 0, 1)`、进入 `cubic-bezier(0, 0, 0, 1)`、退出 `cubic-bezier(0.3, 0, 1, 1)`：标准曲线用于屏幕内移动或改变尺寸（侧栏收展、折叠展开、设置页滑入／滑出、Drawer 进出），进入／退出曲线用于 Modal、Popover、Menu、Toast 的出现与离开；时长以 `--pwa-duration-*` 定义（侧栏 220ms、设置页与 Drawer 200ms 等）。Drawer（移动导航、移动电脑选择、工具与文件阅读器）与设置页转场统一为覆盖模型：200ms 标准曲线纯位移、进出同长，只有上层面板移动，下层视图保持原位，面板全程不透明、不叠加淡化，遮罩以同一时长与曲线同步淡化。减少动态效果只跟随系统 `prefers-reduced-motion`，由一处全局规则把位移、缩放与尺寸过渡改为约 120ms 的颜色与透明度淡化，并将 `--pwa-motion-shift` 置 0；加载指示器、运行中图形等状态动画照常运行 |
| 悬停与触屏 | `:hover` 反馈（`hover` 浅底、颜色变化）只写在 `@media (hover: hover)` 内，避免触屏点击后残留悬停态；需要按下反馈的行（如折叠头）另用 `:active`，松手即消失。取消 Mantine 默认悬停样式的覆盖规则不受此限。键盘 `:focus-visible` 不受影响 |
| 图标 | Lucide，经 `LucideProvider` 统一线宽 1.8；尺寸只用 16（按钮内、元数据、状态行）、20（图标按钮与导航）、24（空状态等大尺寸）。例外：与 13px 状态文字同行的运行中旋转图标为 12（连接状态、导航行） |
| Mantine | [`piReachTheme`](../pwa/src/lib/ui/pi-reach-theme.ts) 的字号、间距（xs–xl 依次为 8／12／16／24／32）、圆角与阴影引用上述 token，断点以 em 字面量对应 768px；`piReachCssVariablesResolver` 把 Mantine 语义颜色变量（body、text、dimmed、default、primary、disabled、overlay 等）映射到同名角色，不维护平行色值 |

### 品牌资产

标识为「桥」：单色几何 π，一体化横梁、柔和外侧端点与延伸右腿，无角标。界面内以 [`BrandMark`](../pwa/src/components/pwa/brand-mark.tsx)（`currentColor`）绘制。favicon（`icon.svg`）为雾蓝 `#446396` 圆角底加白色标识；安装图标（`app-icon-192/512.png`，同时用于 `any` 与 `maskable`）和 `apple-touch-icon.png` 为满版雾蓝底，标识位于中央 80% 安全区内；`logo.svg` 为透明底雾蓝单色标识；界面内侧栏与启动页的 `BrandMark` 用 `ink`。这些文件由 `pwa/scripts/render-brand-icons.mjs` 生成。独立「Pi Reach」字标见 [`branding/wordmark.svg`](../branding/wordmark.svg)，复用相同的「桥」几何与系统字体；根 README 使用当前 `pwa/public/logo.svg`，历史黑底蓝点 Logo 不再作为现行入口。浏览器主题色跟随 `bg`（浅色 `#FFFFFF`、深色 `#1E1E1E`）。

## 界面语言

界面提供简体中文与英文。设置中的「语言」有「跟随浏览器」（默认）、「中文」、「English」三项；手动选择保存在当前浏览器的 `pi-reach-language`，选回「跟随浏览器」即清除。跟随浏览器时按 `navigator.languages` 顺序取第一个中文或英文条目，任何中文区域都显示简体中文，其余显示英文；浏览器语言变化时随之更新。切换立即生效、不刷新页面，同步 `<html lang>`（`zh-CN`／`en`），时间与数字按界面语言格式化，进行中的连接、发送与配对不受影响。

文案集中在 [`lib/i18n/messages`](../pwa/src/lib/i18n/messages/en.ts)：`zh.ts` 由类型约束与 `en.ts` 结构一致，测试校验每一项都有中文。组件通过 `useI18n()` 取文案，切换语言后重新渲染；非组件代码用 `getMessages()` 按调用时的语言取值。错误与反馈沿用英文原文作为内部标识，经 `safeFeedbackMessage` 白名单过滤后，展示时由 `localizeFeedback` 换成当前语言。只翻译应用自有文案（操作、状态、错误和可访问名称），不翻译用户或 Pi 的消息、电脑与用户自定会话名称、历史原文、路径和命令；扩展写入的默认名 `Untitled session` 视为未命名，按当前语言显示「未命名会话」／「Untitled session」。DOM 查询不得依赖可访问名称文本，改用类名或 `data-*` 属性。

## 布局与导航

布局为「导航常驻」。视口宽度 ≥ 768px 为桌面：不设全局顶栏，应用底色为 `panel`；侧栏宽 260px、贯通全高、贴边，与主区之间不加分割线；主区是内嵌卡片（`bg` 底、圆角 12，不加阴影和边框），上、右、下与窗口边缘相距 8px，侧栏收起后左侧同样相距 8px，遇到安全区时取两者较大值（见 [ADR-20261010](adr/20261010-desktop-inset-main.md)）。主屏 PWA（如 iPad）的状态栏按「状态栏与顶部区域」处理，品牌行与收展入口同样避让。侧栏自上而下为品牌行（`BrandMark` 与「Pi Reach」）、电脑选择入口、「在线 Pi」与「本地历史」两个分组（共用一个滚动区），底部固定「配对电脑」与「设置」两个文字按钮。只配对一台电脑时，电脑选择入口收成无框的一行（在线圆点、电脑名与展开箭头，高 44px），多台时为带图标与「当前电脑」副标题的卡片。电脑列表、配对、重命名和删除配对集中在电脑选择面板：桌面为 Popover，移动端为底部 Drawer。未配对时侧栏只显示电脑选择入口（「未配对电脑」）与底部入口。

侧栏可以完全收起，状态保存在当前浏览器的 `pi-reach-sidebar-collapsed` 中。收展入口是成对的左右箭头（`ChevronLeft`／`ChevronRight`），无常态外框：展开时位于侧栏品牌行右端，收起后停在主区卡片标题区左端（距卡片左缘 8px），与标题同一行（标题区左侧留白 `56px`），不与导航列表重叠（见 [ADR-20260929](adr/20260929-sidebar-toggle-placement.md)）。侧栏以 220ms 标准曲线收展，主区卡片左边距与收展入口的位置同步过渡；收起时主区卡片占满可用宽度，阅读列与输入区随之重新居中；收起的侧栏以 inert 隔离焦点，不卸载导航内容。

主区卡片顶部是 48px 的会话标题区（桌面标题区位于卡片内，比未避让状态栏的侧栏品牌行低 8px）：左侧为「工作目录最后一级 · 会话名」（目录用 `secondary`），本地历史在会话名上方以小字标出「本地历史 · 只读」；右侧依次为连接状态、刷新和会话「更多」。未打开会话时只保留状态与操作。连接提示条与错误提示位于标题区下方，与阅读列同宽；Toast 为标题区下方居中的浮层（见「反馈呈现」）。消息阅读列与输入区最大宽度都是 680px，左右留白桌面 20、移动 16px。

视口宽度 < 768px 为移动布局：主区单栏，会话标题区即顶栏，不显示 Logo；顶栏、导航与全屏叠层的状态栏避让见「状态栏与顶部区域」；没有配对或未选中电脑时，顶栏标题为「Pi Reach」，已选中电脑但未打开会话时为电脑名。菜单图标与当前会话名（本地历史时上方加「本地历史 · 只读」）共同构成导航入口，悬停和聚焦只在图标周围显示圆形反馈，入口保持 44px 点击高度；右侧为连接状态与「更多」，不显示刷新；已连接时连接状态只显示圆点（文字仅供读屏），其他状态照常显示文字。导航为左侧 Drawer，宽 `min(320px, 85vw)`，贴边的左侧为直角、右侧两角圆角 12，进出按「基础层」的 Drawer 动效，顶部为品牌与关闭按钮，内容与桌面侧栏一致，遮罩使用 `scrim`；移动导航不继承桌面收起状态。选择 Pi、历史或进入配对／重命名前先完成导航退出；进入设置时导航不先播放关闭动画（见「设置页」）；删除配对确认保留底层导航。所有叠层 Portal 到 `.pwa-root`（移动导航挂在工作区视图内，设置页转场时随工作区保持原位、被设置层覆盖），Escape 只关闭当前最上层，关闭后恢复有效焦点。

### 状态栏与顶部区域

主屏 PWA 的状态栏统一为 `black-translucent`，不按页面切换：页面延伸到状态栏下方，状态栏区域透出其下方界面的颜色。所有贴着屏幕顶边的顶栏使用同一规格，不按页面各定一套：移动会话标题区、桌面侧栏品牌行、移动导航头部、工具与文件阅读器顶栏、移动设置页顶栏。桌面会话标题区位于主区卡片内，不贴屏幕顶边：卡片上边距取 `max(8px, 状态栏安全区)`，标题区本身固定 48px，尺寸、左右内边距与标题规格仍同顶栏。

- **尺寸**：高 `--pwa-topbar-height`（48px，44px 按钮上下各留 2px），安全区 `--pwa-safe-top` 叠加在上内边距，不压缩顶栏；标题与 44px 图标按钮在顶栏内垂直居中、处于同一条中线，不另加上下留白。顶栏只放单行内容，完整命令等长内容放进正文。
- **左右内边距**：以图标按钮开头时距边缘 4px，按钮与标题相距 4px（移动标题区、移动设置页、移动阅读器）；以文字开头时取 `--pwa-gutter`（桌面 20px；桌面标题区与阅读器）；导航品牌与下方列表左缘对齐（16px）。右侧图标按钮距边缘移动端 4px、桌面 8px。
- **标题**：统一 `--pwa-text-title`（18px）加粗，单行，过长时省略；标题左对齐，紧随左侧按钮或从左边距开始，不水平居中。桌面设置页不设顶栏，标题为 24px（见「设置页」）。
- **返回与关闭**：移动端全屏页面与阅读器在左侧放返回箭头（与右滑关闭方向一致）；桌面右侧 Drawer 在右上角放关闭。
- **底色**：顶栏与所在图层同底色。主界面与设置页为 `bg`，桌面侧栏、桌面主区卡片上方与移动导航为 `panel`，工具与文件阅读器也为 `bg`（与主界面同色，桌面 Drawer 靠阴影与遮罩和主区分开）；状态栏区域因此显示最上层顶栏的颜色，叠层遮罩 `scrim` 也覆盖状态栏。
- **滚动**：可滚动内容不得进入状态栏区域。顶栏固定在滚动区之外或以 sticky 吸附；桌面设置页没有顶栏，在滚动区顶部吸附一条高 `--pwa-safe-top`、与页面同底色的遮挡条，不占布局高度。
- **主题色**：`theme-color` 在运行时跟随外观取 `bg`（浅色 `#FFFFFF`、深色 `#1E1E1E`），不随页面或叠层变化。浏览器标签页和不支持透明状态栏的平台（如 Android 主屏）在打开阅读器等叠层时，状态栏颜色可能与叠层顶栏不同。
- **应用高度**：iOS 在该模式下会把 fixed 定位的初始包含块缩短一个状态栏高度，独立窗口因此以 `100lvh` 作为应用高度，Drawer 与 Modal 相对 `.pwa-root` 定位，导航、遮罩和底部面板铺到屏幕底边。
- 新增的顶栏复用 `.pwa-topbar` 与 `--pwa-topbar-height`，并补充状态栏避让的浏览器测试；底部面板（如电脑选择 Drawer）和居中 Modal 的头部不贴屏幕顶边，不属于顶栏。

### 左右安全区

横屏刘海与圆角的左右安全区以 `--pwa-safe-left`／`--pwa-safe-right` 表示（无安全区时为 0，桌面浏览器外观不变）。宽度 ≥ 768px 的横屏手机进入桌面布局，同样适用。原则：安全区只由实际贴住该屏幕边缘的布局层负责，同一边只算一次；贴边层的背景延伸进安全区、内容内缩，子层不再叠加；不贴边的居中叠层与屏幕边缘的距离取 `max(基础留白, 安全区)`，不相加。侧栏 260、阅读器 720、移动导航 320 都是内容宽度，不含安全区；设置页 640 与阅读列 680 位于已扣除安全区的区域内。

| 布局层 | 口径 |
| --- | --- |
| 桌面侧栏（展开） | 面板总宽 260＋左安全区，安全区内为 `panel` 底；收展入口随之右移 |
| 桌面主区卡片 | 不贴屏幕：上、右、下与屏幕边缘相距 `max(8, 对应安全区)`，侧栏收起后左侧同样；卡片内部不再叠加安全区，标题区右侧 8、左侧 gutter（收起后 56），阅读列、输入区与提示区左右 gutter；收起后展开入口距卡片左缘 8 |
| 移动主区 | 左右都贴边：移动顶栏左右 4＋各侧安全区，阅读列与输入区 gutter＋各侧安全区，输入区底部取 `max(16, 底部安全区)`；软键盘弹出时底部安全区被键盘遮住，按 0 计 |
| 设置层 | 页面自身内缩左右安全区，内部 640 容器及其 20／16 内边距不变 |
| 桌面右侧阅读器 | 面板总宽 720＋右安全区，不超过视口；顶栏与正文右侧内缩右安全区 |

### 移动端滑动

移动布局支持单指滑动，面板在拖动过程中实时跟随手指；松手后达到识别阈值才提交，复用已有按钮的打开、关闭或返回入口，不改变 history 和焦点规则，未达阈值或反向甩回则回弹。无法跟手时（减少动态效果、起点落在边缘排除区、收尾期间再次按下）退回触发式：松手一次判定，不移动面板。阈值以 [`swipe-gesture.ts`](../pwa/src/components/pwa/swipe-gesture.ts) 的具名常量为准，不在文档中重复维护。桌面宽度、鼠标和触控板不启用。

| 表面 | 手势 | 启用条件 |
| --- | --- | --- |
| 工作区主区 | 右滑打开移动导航；关闭后焦点回到标题区导航入口 | 设置页未打开且无页面转场，导航未打开 |
| 移动导航 | 左滑关闭 | 导航已打开，电脑选择面板未打开 |
| 设置页 | 右滑按原来源返回工作区或展开的导航 | 设置页已打开且无页面转场 |
| 工具详情阅读器 | 右滑关闭 | 已打开且为移动全屏 |
| 文件阅读器 | 右滑关闭 | 已打开且为移动全屏，仍服从原模态关闭门禁 |

按下与提交前都检查阻断叠层：当前表面自身所在 Drawer 之外，可见的 dialog（包括非模态会话信息）、menu 或 listbox 均阻止触发；退出期间带 `inert` 或 `aria-hidden="true"` 的叠层不阻断。输入控件、可编辑内容、整个 Composer、`data-swipe-ignore` 区域、有文字选区或起点祖先中真正可横向滚动的区域均不识别。第二触点、取消事件、表面禁用或卸载会取消本次滑动；按钮、键盘、Escape、遮罩和系统返回继续可用。

移动端需在手势表面及其纵向滚动容器设置 `touch-action: pan-y`，不能只设置最外层。嵌套代码块、表格和 diff 横向滚动区保持默认 `auto`；图片舞台显式退出滑动关闭，保留 `touch-action: none` 的拖动和缩放。文件 Markdown 的围栏代码块与表格一样在块内横向滚动，不撑宽正文，因此从正文其他位置起手仍可右滑返回；若其他内容仍使正文自身横向溢出，整个正文滚动区动态保留 `auto` 并排除滑动关闭，不为手势改变内容换行。以后新增滚动容器须核对最近滚动容器的 touch-action。

手势不限定屏幕边缘：主区中部也可右滑。浏览器或系统占用的边缘返回继续交给既有 history 流程；桌面 Chromium 的移动视口和 CDP 不能代替 iOS／Android 真机验收。

跟手拖动用暂停的 WAAPI 动画随手指移动，拖动期间不改 React 状态；面板位移自方向锁定那一帧起算，反向不越过起点。松手后从当前位置按标准曲线走到终点或起点，时长随剩余位移与松手速度缩短，不长于 `--pwa-duration-drawer`／`--pwa-duration-page`。拖动与收尾期间对目标元素关闭 CSS 过渡（`data-swipe-drag-active`），否则 Mantine 的退出过渡会盖过脚本动画。

| 表面 | 跟随的元素 | 提交与取消 |
| --- | --- | --- |
| 工具／文件阅读器、移动导航关闭 | Drawer 内容与遮罩 | 走到终点后调用一次原关闭入口，退出时长为 0；入口被门禁拒绝（上层确认框等）时回弹，不改 history，之后按钮关闭仍有完整退出动画 |
| 设置页返回 | 设置层与页面遮罩（工作区层保持原位） | 松手即调用原返回入口，路由变化后由页面转场从当前位置续播；1 秒内路由未变则恢复设置页。来源为导航时拖动开始即预挂载展开的导航，工作区仍 `inert`，不启用焦点陷阱，提交后焦点落在导航内的「设置」；回弹则撤销预览与待处理焦点请求 |
| 移动导航打开 | Drawer 内容与遮罩 | 开始时同步挂载并打开导航，期间无焦点陷阱与滚动锁，焦点不动；提交后启用并按现有规则聚焦，回弹后即时关闭且不回焦 |

拖动或收尾中表面被外部关闭（Escape、`popstate`、按钮）时不回弹，从当前位置走到关闭终点，且不再调用关闭入口；取消事件不代表表面状态，仍打开才回弹。导航打开手势被外部关闭后作废，同一次松手不会重新打开。向右拖动的起点落在左缘 24px 内且不是 standalone 时不跟手，避免与浏览器后退手势同时移动；standalone 没有系统边缘返回，不排除（待真机核对）。减少动态效果时位移为 0，不启用跟手。

### 设置页

设置是独立页面，地址为 `/app/settings`，桌面与移动一致，不保留工作区侧栏。页面以 `bg` 为底、内容最大宽 640，自上而下为返回入口、页面标题「设置」与五个分区：外观、语言、连接（Relay 地址与主操作「保存设置」）、浏览器数据（「重置布局」与危险入口「清除本地数据」）、关于，分区间距 32。外观与语言为单选卡片：`surface` 底、1px `line` 边框，选中时边框改为 `ink`，只有选中的单选圆点用 `accent`，未选中的圆点轮廓用 `control-line`。桌面返回为带文字的按钮（「返回工作区」），标题 24px 在其下方；移动端返回箭头（44px，与其他图标按钮同为 `secondary`、悬停为 `ink`，可访问名称随来源为「返回导航」或「返回工作区」）与 18px 标题同一行，组成固定顶栏；桌面不设顶栏，滚动时由状态栏遮挡条避让（均见「状态栏与顶部区域」）。保存后留在设置页并以 Toast 提示「设置已保存」。

「关于」以左侧名称、右侧版本的三行列表显示 PWA、Relay 与扩展版本，下方注明当前电脑与 Pi；没有选中在线 Pi（包括阅读本地历史）时不显示对象说明。连接或握手期间显示「正在获取版本…」，离线显示「未连接」，没有当前在线 Pi 时扩展显示「未选择在线 Pi」。版本信息不按三端数字是否相同判断兼容性。标题右侧提供「复制版本信息」图标按钮，复用现有复制反馈，只复制版本与必要状态，不包含 Relay URL、电脑名、会话名、路径或身份信息。

进入时 `pushState` 一条记录，state 保存来源（工作区，或已展开的移动导航及其滚动位置）；页内返回与浏览器／系统后退都回到上一条记录并按来源恢复：回到工作区时保留会话、草稿与阅读位置，焦点回到侧栏的「设置」；回到移动导航时导航以展开态直接呈现并恢复滚动位置，焦点落在导航内的「设置」。直接打开或刷新 `/app/settings` 停留在设置页，并在其下补一条工作区记录，返回后再后退不会回到设置页；浏览器前进重新进入时照常播放进入转场；系统已为本次历史导航提供原生视觉转场（`hasUAVisualTransition`，如 iOS 边缘手势）时不再叠加应用转场，直接呈现目标视图；未识别的 `/app/*` 显示默认工作区并把地址改回 `/app`。进入后焦点落在页面标题（可程序聚焦、不在 Tab 顺序中），标签页标题改为「设置 · Pi Reach」，返回后恢复；直接打开时不移动焦点。移动布局的右滑返回与页内返回共用入口，启用和排除规则见[移动端滑动](#移动端滑动)。清除本地数据后重新载入工作区。

转场与右侧 Drawer 同一覆盖模型，200ms（标准曲线）：进入时工作区保持原位，设置页带 `--pwa-shadow-modal` 与左侧两角 12 的圆角从右滑入并覆盖（静止后去掉阴影与圆角），其下的 `scrim` 遮罩同步淡入；返回时反向；中途反向或由跟手拖动交接时从设置层与遮罩的当前状态继续。遮罩只在转场与拖动期间可见，不拦截点击。从导航进入时，导航随工作区保持原位、被设置页覆盖，滑入完成后直接卸载，不播放关闭动画。减少动态效果时改为交叉淡化。

桌面与移动端的会话「更多」是非模态的只读信息弹层：完整会话名（换行不截断）、工作目录完整路径（等宽、无框的原生只读文本字段）、电脑名 · 状态。触发器与弹层的可访问名称均为「会话信息」，弹层采用 `dialog` 语义，打开时焦点进入信息区；Tab 可进入路径字段，使用系统全选与复制快捷键，Escape 关闭后回到触发器；点击外部关闭时不抢走外部控件的有效焦点。路径字号为 16px，避免移动浏览器聚焦输入时缩放。没有目录时信息区仍可聚焦。在线会话、已退出的 Pi 与本地历史均不在此提供命令或连接重试操作；新会话、压缩上下文、模型与思考级别从输入区进入。会话名在导航与顶栏中单行截断，悬停以 `title` 显示全名。

## 组件规则

- **电脑与活动 Pi**：电脑是持久 pairing；活动 Pi 仅来自当前 Relay snapshot，列表名称使用当前 Pi 会话名称，重命名及切换会话后同步更新。状态徽标同时给出文字和图形状态，不能把缓存 metadata 画成在线。
- **在线 Pi 行**：与历史条目同为最小高 44、内边距上下 6 左右 8、行间 2 的导航行，文字与品牌、分组标题同一左缘（距侧栏 16）。第一行为会话名（未命名为「未命名会话」），第二行为工作目录最后一级 · 运行中（运行色＋动态图形）或空闲；不显示模型名。当前项为 `selected`＋`ink`，悬停时保持不变，以 `aria-current` 标记并保持可聚焦。非当前查看的 Pi 由运行中变为空闲时，行右侧显示直径 6px 的 `accent` 圆点（读屏为「有新回复」），移动端菜单图标右上角同样显示；打开该会话后消失，只保存在页面内存中。等待 Relay 快照时分组内显示骨架行，没有在线 Pi 时只有一行「没有在线的 Pi」。
- **历史条目**：历史是 PWA IndexedDB 中已保存的正式 timeline scope，而不是远程 Pi session 列表，只列当前电脑的记录。第一行为已保存的会话名，缺失时回退到纯文本消息预览（仅清理常见 Markdown 标记、保留链接文字）；第二行只有时间：今天显示时刻，昨天显示「昨天」，更早显示日期。先显示 20 条，「显示更早的记录」每次追加 20 条。在线 Pi 的当前会话只出现在「在线 Pi」分组，本地历史不重复列出：当前选中的 Pi 隐藏已握手的实时会话，其他在线 Pi 隐藏它在本浏览器中最近更新的一条记录；Pi 退出或切换会话后，这些记录回到本地历史，正在阅读的历史始终保留。某个 Pi 在未被查看时切换了会话，它的上一段会话会暂时隐藏，直到打开该 Pi 或它退出。打开历史后输入区位置换为 `panel` 底只读说明条，若该会话对应的 Pi 在线则附「回到在线会话」；点击在线 Pi 也可退出历史。
- **会话正文**：用户、Pi 回复、思考与独立工具行保持事件顺序；扩展 `custom` 事件暂不渲染原始 payload，压缩与分支摘要仍显示。不用头像，也不逐条标发送方或时间：用户消息靠右、`message` 轻底，Pi 回复靠左占满阅读列、无底色，每条前有仅读屏可见的「你：」「Pi：」。一轮回复（同一 `group_id`）连续排列；只有收到本轮正式 `run_end` 后才在末尾显示一次完成时间（13px／`secondary`），中断或出错时附状态文字，进行中不显示。等待 Pi 首段输出时在回复位置显示「Pi 正在思考…」。待发送消息在气泡下方以一行小字显示「发送中」或失败原因，失败时附文字按钮「重试」「取消」；模型错误以错误色图标＋文字行呈现。
- **Markdown**：标题分两级（`#`／`##` 18px、其余 16px，均 600），段落 16px／1.65；链接 `accent` 常显下划线并在新标签页打开；行内代码 `panel`＋`soft-ink`；引用左侧 2px `control-line` 竖线；宽表格自身横向滚动。代码块使用 `code-surface`、圆角 8，按围栏语言以 highlight.js 高亮（超出大小上限时不高亮）；顶部为高 36px 的标题栏，左侧为围栏语言名（等宽 13px、`code-dim`，无语言时留空），右侧为复制按钮（点击区 44px，上下以透明扩展区越出标题栏）；标题栏下方的代码区只负责横向滚动，长行不会滚到按钮下方。
- **思考与工具行**：状态行无分割线，行间距 6px；一轮结束后，其中相邻且状态已有定论的工具（成功、失败、中断，至少两条）合并为一行摘要（如「读取 2 个文件 · 运行 1 条命令」，按类别计数、按首次出现排序，读取、修改、写入按不同路径计数），含失败时摘要末尾追加「N 项失败」并在右侧显示错误图标，含中断时另追加「N 项已中断」、不显示错误图标；摘要左侧显示描述、右侧显示折叠箭头，不显示完成对勾；若用户正在阅读某个尚未合并的工具的详情，该段暂不合并，退出阅读器后再合并，已在组内的工具不受影响；展开后只列出各工具的标题、描述与状态，不整块缩进，左侧以 2px `control-line` 竖线（与 Markdown 引用同色）加 12px 内边距标示从属；尚未收到 `run_end` 或仍有同组流式内容的一轮逐条显示，不根据 Pi 空闲、后续组或工具状态推断结束；缺少 `run_end` 的历史也不合并（见 [ADR-20260930](adr/20260930-strict-run-completion.md)）；夹有正文、思考或已发布文件时断开，状态未知的工具不参与合并，仍逐条显示；工具组默认收起，展开摘要暂停自动跟随；单条工具完成时只显示对勾图标，运行中、失败、中断与未知状态显示图标加文字，各状态的可访问名称都保留。单条工具不显示折叠箭头，标题以工具名＋命令／路径呈现，与 Pi 回复左缘对齐；点击整行直接打开工具详情阅读器，无论输出长短都不在对话中展开参数或结果。思考行标题取推理文本里第一个整行加粗（`**…**`）的标题，流式阶段取目前最新的一个，没有则为「思考过程」；标题是模型原文，不翻译，界面文案（「思考过程」「思考中」）随界面语言切换。思考行与工具组一样折叠箭头在行右侧，标题与 Pi 回复左缘对齐，单行省略；流式输出时在箭头左侧显示旋转图标与「思考中」，结束后消失。不显示时长，仍默认折叠。展开内容不整块缩进，左侧 2px `control-line` 竖线加 12px 内边距，规则与工具组展开一致。
- **工具详情阅读器**：桌面为右侧 720px Drawer（横屏另加右安全区，见「左右安全区」），移动端全屏，进出按「基础层」的 Drawer 动效。顶栏标题为工具名，右侧依次为状态图标（与会话内工具行一致只显示彩色图标，文字仅供读屏与悬停提示）、复制全部与（桌面）关闭，移动端左侧为返回（见「状态栏与顶部区域」）；顶栏与正文同用 `bg`，桌面 Drawer 靠阴影、遮罩与左侧两角 12 的圆角和主区分开；移动全屏只在进出与右滑关闭时显示左侧圆角。正文首块为调用参数，所有工具一致、不做推断或省略（等宽、不截断、可选中）：每个参数一行「名称: 值」，文本值原样显示（保留换行、不转义），其他值显示为 JSON；没有参数时不显示该块，正文只放工具真实返回的结果，不再从参数复制内容（不单列「参数」块，也不显示 write 的内容或 edit 拼出的请求修改；会话内展开仍显示）。调用参数排满一行再按字符断开，下方以 1px `line` 分割线与输出分开（上下各留 12px）。其后为原始输出，与 Pi 原生一致不带行号，与调用参数同一左边线，不做语法高亮，diff 以轻底加 3px 左侧色条区分增删；停在底部时跟随流式更新。打开时压入一条不改变 URL 的历史记录，系统返回或浏览器后退只关闭阅读器，系统已提供原生返回转场时直接关闭、不再播放退出动画；关闭后焦点和阅读位置复原。移动全屏的右滑关闭规则见[移动端滑动](#移动端滑动)。
- **已发布文件**：合法发布 custom 独立呈现，不显示原始 payload；文件行打断工具摘要，沿用本轮分组，发布确认后立即显示，不等整轮结束。文件名、类型和大小使用只读 metadata；获取后以当前内容信息为准。合格的小图片接近视口时最多自动获取一次，大图和其他格式由用户手动获取；失败或取消后仅手动重试。自动获取与格式、尺寸边界见[会话协议](reference/protocol/protocol-v2.md#会话文件发布与获取)；自动图片限 10 MiB，手动查看允许合格的最大 50 MiB 图片或文本。完整校验前只显示获取进度与取消，不展示半张图片。获取进度与获取错误原地替换大小行（细进度条加「获取 N%」；错误单行截断，完整文字见 `title`；图片占位区已显示错误时大小行不变），卡片高度不随状态变化。由「查看」触发的获取完成后，进度条补满并显示「完成」，停留 `--pwa-duration-fetch-settle`（600ms，参照骨架屏至少显示 500ms，避免完成态一闪而过；减少动态效果时不缩短）再打开阅读器，阅读器打开后卡片不保留进度；已获取的文件直接打开。获取完成后显示「保存」链接，由新的用户手势交给浏览器下载；不异步自动保存，也不声称已写入用户设备。卡片操作全部只显示图标：「查看」与「获取」（Eye）、「下载」与「保存」（Download）、「取消」（X）、「重试」（RotateCw），名称作为 `aria-label` 与 `title`，与其他图标按钮同规格（点击区域 44px、直径 36 的圆形反馈、常态 `secondary`）；阅读器顶栏的「保存」同样只显示图标。
- **文件阅读器**：单例右侧 Drawer，桌面 720px、移动全屏，复用工具阅读器的动效、焦点和返回规则；顶栏标题为文件名（单行省略），右侧为保存与（桌面）关闭，移动端左侧为返回；打开时暂停会话自动跟随，关闭后恢复来源焦点。图片提供缩放、复位（显示比例的文字按钮）及双指缩放／拖动，解码失败只在明确重试后重新获取。文本正文在进入动画结束后才解析和渲染，滑入期间正文区留空，避免长文本推迟滑入起点。文本完整获取后只预览前 1 MiB，并限制为 64 Ki 个 UTF-16 单元、1000 行；截断有说明，保存链接仍下载完整原件。Markdown 禁 raw HTML、自动图片与危险链接；HTML、SVG 和代码作为转义文本，不嵌入网页或执行。移动全屏的右滑关闭及图片、横滚排除规则见[移动端滑动](#移动端滑动)。
- **文件获取与切换**：获取未完成时，切换电脑、Pi 或历史与附件发送共用一次确认；「留下」继续当前任务，确认后取消并切换，不转投。选择相同目标、普通 leaf 推进和进入设置不算切换。已完整获取的结果在短断线时仍可查看和保存，未完成内容不可使用；只读历史只展示 metadata，不暗中建立远程获取。缓存逐出、刷新与真正目标切换不保证保留内容。
- **Composer**：输入区为唯一一块圆角长方形 `surface` 表面，内层文本框无边框、透明底，圆角为 `--pwa-radius-lg`（12px），不用阴影，聚焦时外层边框改为 `accent`，桌面与移动端一致；附件与 `/` 命令入口为无框图标按钮，文本开头实际键入 `/` 也会打开同一命令菜单（粘贴不触发），菜单只提供 `/new` 与 `/compact`。发送按钮左侧为模型标签：显示当前模型与思考级别（手机只显示模型名；13px／600、`secondary`，视觉高 32、点击区 44，最大宽桌面 240px、手机 160px，超出省略），点击打开单独锚定的「模型与思考」设置菜单，根视图提供「切换模型」与「思考级别」，分别进入选择列表，返回只回到设置根视图，不包含会话命令。这是模型与思考级别的唯一入口，离线时不可用；尚未取得模型名时仍显示「模型与思考」，避免思考级别入口缺失。排队消息位于输入区上方，操作行包含状态、单行正文、插入与取消两个无框图标按钮；附件另以只读卡片展示，两条以上显示标题与计数，有投递提示时下方补一行说明；撤回在取消被确认后把文字放回输入框（空草稿直接填入，已有草稿换行追加，同租约的附件以描述回填，旧图片只在没有附件时回填），已被 Pi 读取的不回填。发送使用上箭头和常显 36px 强调色圆，空草稿时降低透明度并禁用；Pi 运行中无论草稿是否为空，发送位置只显示停止按钮，草稿仍可编辑；停止按钮与发送按钮同形同色（36px 强调色圆、实心方块图标，不显示文字），停止中显示旋转图标并暂不可用。发送、停止、附件和命令入口均须保持 44px 触控目标。文字与附件草稿按实际电脑、Pi 实例和会话分别保留，不把旧回执用于清空用户后续编辑的文字。断线时仍可继续输入，但发送、附件与 Pi 命令不可用，下方提示「连接恢复后才能发送」；只读历史与已退出的 Pi 用说明条代替输入区。
- **会话附件**：多选文件、粘贴和相机均保留原 File，选中不上传，点击发送后才上传。附件区在输入框外上方，桌面双列横排换行、手机纵排；卡片 58px 高，文件名截断且可查看完整 title，预览失败使用文件图标，所有操作域至少 44px。超过两件的纯草稿可折叠，上传中的逐件取消始终可达。只有逐文件进度，不加总进度；成功视觉只保留 ✓，失败显示短原因和重试／移除、不保留进度条。发送级提示在附件区上方、左对齐、无边框，无提示不占位；输入框保留自身边框，不在消息区与输入区间加分隔线。上传期间暂不可编辑文字或新增文件；逐件 × 停止并移除该件，其他继续，最终保留件全部就绪后自动提交，失败未移除仍阻止提交。全部移除时有文字只发文字，无文字不发空消息。设置页、普通 leaf 推进和短断线不算切换；切换电脑、Pi 或历史须确认停止本次发送并保留原目标草稿，不转投。正式消息、pending 和队列复用只读卡片，无原件下载或大图弹窗；旧 inline 图片历史继续可读。
- **按钮与输入**：主操作为实心 `accent`＋`on-accent`（每个视图最多一个），次级为 `surface`＋1px `line`（Mantine `default` 变体，不用 `light`），文字按钮为 `accent` 文字、悬停 `hover` 浅底，危险入口（会弹出确认的操作）为错误色轮廓，危险确认为实心错误色＋`on-status`，仅用于确认弹窗的最后一步；禁用为 `disabled-bg`＋`secondary`，不靠透明度。无框图标按钮透明底、44px 点击区域，悬停显示直径 36 的圆形 `hover` 浅底，聚焦为圆形轮廓；实心发送与停止按钮常显 36px 强调色圆。表单输入单行高 44、`surface` 底、1px `control-line` 边框，标签在上（与输入框间隔 8）、说明在下，聚焦加贴边强调色轮廓且边框不变。
- **主区空状态与加载**：位于阅读列中部偏上，自上而下为 24px Lucide 图标（`secondary`）、标题（18px／600）、一行说明，最多一个操作，不用插画。间距只由各元素的上外边距负责：图标到标题 16、标题到说明 8，说明到命令块、操作或列表 16。启动失败页为最大宽 520 的卡片（`surface`、1px `line`、圆角 12），内边距桌面 32、移动上下 24 左右 16，状态图标块 48×48 内含 24 图标。未配对显示「还没有配对的电脑」、一句说明「在电脑上的 Pi 中运行下面的命令。」、单独一行的 `/pi-reach pair` 命令块（`panel` 底、高 44px、右侧复制按钮）与主操作「开始配对」；已配对无在线 Pi 显示「没有在线的 Pi」，有本地历史时附文字按钮「查看本地历史」；多个在线 Pi 且没有可沿用的选择时，主区标题为「有 N 个在线的 Pi」，下方以有边框的可点行列出（`surface` 底、1px `line`、圆角 8、最小高 56，运行中的排在前面，右侧箭头）；新会话无消息时显示「向 Pi 发送消息开始。」，下方一行 13px 小字为「目录 · 模型 · 思考级别」（缺项省略），桌面首次进入空会话时聚焦输入框，移动端不自动弹出键盘。等待快照或打开会话时使用 `hover` 色骨架屏：300ms 内完成不显示，出现后至少 500ms，约 1.5 秒明暗呼吸，减少动态效果时静止；打开会话时骨架行显示在消息列表内，列表保持挂载。
- **反馈与错误**：按来源与生命周期选择连接 banner、Toast、局部错误或持久提示，具体规则见下文。低频状态使用 live region，提示不能遮挡 Composer 或主动夺取焦点。
- **表单与叠层**：配对、重命名、清除数据等操作保留明确取消路径。叠层自下而上为页面 → 固定元素（顶栏、输入区、连接提示条）→ Drawer（移动导航、工具阅读器、移动电脑选择）→ Modal（配对、重命名、确认）→ Menu／Popover → Toast。遮罩始终只有一层：Modal 叠在带遮罩的 Drawer 上时下层遮罩隐去。居中 Modal 统一轻量进出：遮罩淡入、弹窗上移 8px 并淡入，进入 180ms（进入曲线）、退出 140ms（退出曲线），退出期间不接收指针，关闭开始时焦点即回到来源控件；减少动态效果时只淡化。宽度确认类 400、表单类（配对、重命名）480，移动端两侧各留 `max(16px, 左右安全区)`。底部操作区按钮间隔 8；对齐的操作组使用最小宽：确认弹窗 120、重命名弹窗 88，单独出现的页面按钮不加最小宽。移动端确认弹窗按钮纵向全宽，重命名弹窗两按钮等分。关闭顺序、焦点和 Escape 竞争按组件测试契约验证。
- **配对弹窗**：说明「在电脑上的 Pi 中运行 `/pi-reach pair`」，提供扫码、上传二维码图片、输入配对码三种方式：可扫码的移动设备默认扫码，其余默认显示配对码输入框，其他方式以文字按钮置于下方。摄像头只在切换到扫码时请求，不可用时说明原因并切回输入。配对码自动转大写，允许 `-` 与空格，输满 8 位有效字符自动提交；扫描或上传得到的码回填到输入框。连接中在弹窗内显示运行色「正在连接电脑…」，输入与按钮暂不可用。成功后关闭弹窗、进入生成配对码的 Pi 会话并以 Toast 提示「已与〈主机名〉配对」；失败原因按协议错误码映射，显示在输入框下方（错误图标＋说明、`aria-invalid`），保留已输入内容，焦点回到输入框，不使用 Toast。

### Mantine 复用边界

基础控件直接使用 Mantine，公共默认尺寸、variant 和产品 class 由 [`piReachTheme`](../pwa/src/lib/ui/pi-reach-theme.ts) 注入；业务 CSS 保留视觉 token、响应式和领域状态样式。原 `components/ui` 薄包装已移除，不为统一导入路径重新封装组件库 API。`ActionIcon` 保持 44px 触控目标；危险入口使用 `outline` 与 `red`，确认弹窗中的危险确认使用 `filled` 与 `red` 并由 `pwa-danger-confirm` 取 token 颜色。

- **导航项**：电脑选择面板、Online Pi 和历史条目使用 `NavLink`，明确指定按钮语义。当前电脑和离线电脑仍可选择；当前活动 Pi、当前历史项及 snapshot 未就绪时的门禁沿用业务规则。电脑操作菜单是选择按钮的兄弟控件，不能嵌套按钮。
- **菜单与弹窗**：Menu 与 Popover 容器内边距 6；菜单项最小高 44、左右内边距 10、图标与文字间隔 8、圆角 6；当前项 `selected`＋`ink`；禁用项改为 `secondary` 文字，不靠透明度（发送／停止按钮的透明度禁用态除外）。会话信息弹层是只读信息区，保留 8／10 的阅读内边距。命令菜单使用 `Menu`；会话「更多」使用 `Popover`，以非模态 `dialog` 语义展示只读信息，不提供操作菜单项。配对、重命名与确认使用 `Modal`，统一进出与遮罩由 [`piReachTheme`](../pwa/src/lib/ui/pi-reach-theme.ts) 的 Modal 默认值提供；配对码使用 `TextInput`。命令菜单先关闭再执行需要交接焦点的业务动作，保留原有二级视图、取消和回焦规则。
- **空状态与加载**：主区空状态与骨架屏由 `workspace-content.tsx` 的业务组件实现，延迟显示逻辑为 `useDelayedVisibility`。配对等待使用 `Loader`；停止任务和工具状态图标继续表达各自业务语义，不统一替换。
- **文件选择**：普通附件和二维码图片使用 `FileButton`。由菜单触发的文件 input 在菜单关闭后仍须挂载；原有清空 input 的入口继续支持重复选择同一文件。摄像头的原生 `capture` input、图片粘贴、二维码解码和资源释放仍由业务组件处理。
- **折叠与滚动**：`ToolCard` 和 `ThinkingContent` 使用业务组件 [`Collapse`](../pwa/src/components/pwa/collapse.tsx)（非 Mantine `Collapse`）：只在用户切换时以 `grid-template-rows` 伸缩，进入 160ms、退出 120ms，已展开内容的流式增长不重播动画；退出期间 `inert` 并冻结为收起时的内容，结束后卸载（时长＋50ms 兜底），中途反向从当前位置继续。复制按钮统一使用 `CopyButton`。业务布局和原生滚动容器继续承担历史 prepend、流式跟随及触摸行为，不默认改用 `AppShell` 或 `ScrollArea`。

### 反馈呈现

| 来源 | 当前呈现与交互 |
| --- | --- |
| 连接中断、重连、离线 | 会话标题区的 `ConnectionStatus` 立即反映状态：已连接为 `accent` 圆点加中性文字，连接中／重新连接中为运行色加动态图形，离线为中性色，都带文字（移动端已连接时只显示圆点，文字仅供读屏）。断线持续超过 10 秒才在标题区下方显示 `Alert` 提示条（如「无法连接 Relay，正在重试…」与「立即重试」），恢复后撤销；阅读本地历史或 Pi 已退出时不显示。未打开会话时（没有在线 Pi、等待选择 Pi 或等待快照），标题区与提示条只反映 Relay 与网络：Relay 已连接时显示「已连接」，没有在线 Pi 或等待选择都不属于连接故障，不显示提示条。 |
| 一次性全局反馈（Toast） | 用于已复制、设置已保存、连接已恢复（仅在提示条出现过之后）、配对成功、有新版本，以及命令／设置等操作失败。`Notifications` 使用独立 store 与固定 ID：`PwaAppShell` 为入口级 `ServiceWorkerRegister` 和工作区共享单槽控制器，单独挂载组件时各自持有实例。新普通提示替换旧普通提示，当前为错误时普通提示排队；有新版本时显示带「刷新」按钮的高优先级 Toast，普通提示不会挤掉它，错误关闭后可恢复。桌面与移动均为顶部居中、会话标题区下方的最顶层浮层：`surface` 底、浮层阴影＋`line` 边框、圆角 8、最大宽 400，状态图标＋单行文字，可选一个文字操作（点击区高 44，悬停底色高 36）与关闭按钮。不带操作的成功／普通提示 4 秒后自动消失，悬停或聚焦时暂停计时；带操作、更新与错误提示不自动消失，可手动关闭。点击「刷新」执行现有 Service Worker 更新流程。不抢焦点、不拦截其他区域操作，以 `aria-live` 播报；进出为 8px 轻微位移加淡化，不拖拽/滚动关闭。 |
| 附件发送 | 逐件进度与错误留在卡片，发送级失败、断线或租约变更留在附件区上方，不使用 Toast，不暴露本地路径、异常正文或内部 ID。 |
| 文件获取 | 进度、取消、受控错误与重试留在对应文件行；不使用 Toast，不暴露源路径、异常正文或内部 ID。保存原件须另一次用户手势。 |
| 配对、重命名、确认、历史加载和消息投递错误 | 保留在对应表单、会话或消息上下文说明影响与下一步，不用 Toast；现有局部 `PwaStatusToast` 继续承担会话内的局部错误。 |
| PWA 安装与浏览器能力提示 | 使用工作区上方的持久 `Alert`，保留安装操作按钮和按需回焦，不进入全局通知队列，也不占据 Composer 下方；更新提示已由 Toast 承担。 |

反馈状态所有权见[当前架构](ARCHITECTURE.md#pwa-反馈状态所有权)。用户文案说明影响和可执行下一步，不直接展示浏览器异常、协议 payload、内部字段或 UUID。

## 实时与只读历史

活动 endpoint 选择和历史阅读是两个模式。对活动电脑，PWA 在 Relay snapshot 后处理 0/1/N：0 个在线 Pi 显示空状态，1 个可以自动选中，N 个在主区列出供选择（仍保留用户明确选择）。有新的 Pi 上线时不自动切换，只在列表中新增；处于「没有在线的 Pi」时有 Pi 上线即自动进入。用户正在阅读历史时，自动 endpoint 选择暂停，实时更新不得抢走历史视图。

正在查看的 Pi 退出后，会话内容保留在原位，标题区状态变为中性色「已退出」，输入区位置换为说明「这个 Pi 已退出，会话记录已保存在本地历史。」，有其他在线 Pi 时附「选择其他 Pi」；此时同样暂停自动选择，同一目录再启动的 Pi 按新实例处理；同一实例（runtime 不变）因 Relay 重启等短暂缺席后重新上线时，不算退出，恢复实时会话。同一 Pi 进程切换到新会话（如 `/new`）时主区跟随新会话，并在开头以一行居中的 `secondary` 小字标出「Pi 已切换到新会话」。

首次打开某个会话（在线 Pi 或本地历史）时停在底部最新内容；同一次访问中切回看过的会话时恢复离开时的阅读位置：离开时在底部则继续跟随最新输出，否则按离开时顶部可见的行重新定位，该行加载出来之前先停在底部，用户主动往上回看则以用户位置为准。展开思考、工具组或打开详情阅读器仅暂停自动跟随，不立刻标记离开底部；实际滚离底部或收到未读输出时才显示「最新」入口。位置只保存在页面内存中，刷新后清除。

打开历史会关闭当前 session channel，仅从 IndexedDB 读取对应的 `device_id + endpoint_id + session_id + history_generation` 正式 timeline，`MessageList` 使用 `isLive=false`。历史视图不显示 Composer、远程控制或隐式 resume。返回在线 endpoint 后才重新建立实时 session。

## 可访问性与动态效果

- 键盘焦点始终可见；Drawer/Modal 关闭后回到有效的来源控件或已定义后备控件。
- 异步输出不强制滚动阅读中的用户；“Latest”入口提示未读输出。
- 使用 `prefers-reduced-motion: reduce` 时取消位移、缩放、尺寸过渡与平滑滚动，只保留约 120ms 短淡化；设置页转场与各 Drawer（移动导航、电脑选择、工具与文件阅读器）共用 `--pwa-duration-*` token 与 `--pwa-motion-shift` 判断，加载与运行中等状态动画照常运行（见「基础层」）。
- 移动布局使用 `--pwa-app-height`（浏览器标签页为 `100dvh`，随工具栏伸缩；主屏 PWA 为 `100lvh`，即整屏，避开 iOS 缩短的初始包含块）和 `safe-area-inset` token，Drawer、Composer、对话框及列表必须保持可滚动且不遮挡。
- **软键盘**：viewport 声明 `interactive-widget=resizes-content`，支持的浏览器直接缩小布局视口；只缩小 visual viewport 的浏览器（如 iOS）由 `useKeyboardViewport` 兜底，在文本输入聚焦且 visual viewport 被遮挡时把 `.pwa-app-shell` 高度与顶部偏移改为 `visualViewport` 的高度和 `offsetTop`，使顶栏保持可见、输入区贴在键盘上方；布局视口已缩小时不重复扣减，缩放（`scale ≠ 1`）不视为键盘，键盘收起、卸载或 API 不可用时恢复 `--pwa-app-height`。补偿不依赖 768px 断点，手机横屏与平板同样适用；贴底与阅读锚点沿用时间线既有的容器尺寸观察，不另设滚动规则。
- **矮窗口密度**：应用壳可见高度 ≤ 600 时为矮窗口、≤ 450 时为极矮窗口（阈值见 [`use-keyboard-viewport.ts`](../pwa/src/lib/pwa/use-keyboard-viewport.ts) 的具名常量），软键盘弹出同样生效：只压缩消息区上下留白、提示条与 Toast 的纵向空间，运行时提示条说明改为仅读屏可见；不缩小 44 点击区域、字号、左右边距和安全区，提示条图标保持 16。
- **输入区高度**：文字行高 `1.4`，按视觉行增长，高度充足时最多 6 行后内部滚动；上限由实际布局计算（扣除顶栏、通知、队列、附件与输入区非文字部分），不使用固定视口阈值。空间不足时提前内部滚动，textarea 不低于 44px，消息区至少保留一行正文与上下各 8px 留白；仍无法容纳时标记为布局冲突，不隐藏内容或缩小触控目标。
