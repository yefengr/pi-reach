# 工具调用实时分组与折叠方案

本文记录 PWA 会话中工具调用从第一条起即进入折叠组、组头显示当前运行命令、展开选择由用户决定的方案：现状、界面规则、分组与身份、滚动与阅读、实施与验收。本文不独立维护项目级状态，事项状态见 [ROADMAP](../../ROADMAP.md)；当前设计规则以 [DESIGN](../../DESIGN.md#组件规则) 为准，实现完成后把仍有效的规则同步到 DESIGN，再归档本方案。

本方案调整 [ADR-20260930](../../adr/20260930-strict-run-completion.md) 中工具摘要的展示条件，处理方式见「[设计约束与决策记录](#设计约束与决策记录)」。效果稿评审结论及后续修订见「[已确认决策](#已确认决策)」；2026-10-14 确认的批次结束、最短展示时间和图标位置变更见 [ADR 的组头修订](../../adr/20261011-live-tool-grouping.md#工具组摘要与状态图标修订2026-10-14)。

## 目标与非目标

目标：工具调用从第一条开始就进入折叠组。用户不展开时，通过组头了解当前在跑什么；用户展开后，新调用追加到该组最下面。

核心规则：**运行状态决定组头显示什么，用户选择决定组是否展开。运行状态不得覆盖用户的展开或收起选择。**

非目标：

- 只调整 PWA 展示层，不修改 Relay、共享协议或 Extension。
- 不新增工具审批（见[已关闭决策](../../adr/20260518-closed-decisions.md)），不修改工具执行方式。
- 不改变“只有正式 `run_end` 能确认整轮结束”的完成语义。
- 不做展开选择的跨刷新持久化。
- 组头不做循环轮播或跑马灯。

## 术语

| 术语 | 含义 |
| --- | --- |
| 轮 | 同一 `group_id` 的一次运行，以正式 `run_end` 确认结束 |
| 工具段 | 同一轮内展示相邻、未被边界打断的连续工具调用 |
| 工具组 | 工具段在界面上的折叠容器，即组头加可展开的工具行 |

## 现状

以下是 2026-10-11 方案制订时的历史快照，不代表当前实现；当前规则见 [DESIGN](../../DESIGN.md#组件规则) 与上方后续修订。

当时的分组入口是 [`conversation-timeline.tsx`](../../../pwa/src/components/pwa/conversation-timeline.tsx) 中的 `completedToolRuns`，单条工具和组头分别由 [`tool-card.tsx`](../../../pwa/src/components/pwa/tool-card.tsx) 的 `ToolCard`、`ToolGroupCard` 展示。

| 场景 | 方案制订时行为 |
| --- | --- |
| 本轮正在运行 | 工具逐条展示，不形成工具组 |
| 收到本轮正式 `run_end`，且本轮没有流式内容 | 相邻、状态为成功、失败或中断的工具至少两条（`TOOL_GROUP_MINIMUM`）才合并 |
| 工具状态未知 | 不参与合并，仍逐条展示 |
| 正文、思考、可见记录、已发布文件或历史缺口 | 打断工具段 |
| 工具组首次出现 | 默认收起，组头按类别显示计数摘要 |
| 点击单条工具 | 直接打开详情阅读器，不在会话中展开参数或输出 |
| 用户展开工具组或思考 | 暂停会话自动跟随 |
| 阅读尚未合并工具的详情时整轮结束 | 通过 `pinnedKey` 延后该段合并，关闭阅读器后才合并 |
| 等待 Pi 首段输出 | 显示「Pi 正在思考…」，本轮出现任何输出后不再显示 |

需要处理的实现细节：

- `expansionChoices` 按组 key 保存展开选择，组 key 取组内第一个工具的 key，历史向前补齐会改变它。
- 任一工具组或思考展开时 `readingInline` 为真，[`use-timeline-viewport.ts`](../../../pwa/src/lib/pwa/use-timeline-viewport.ts) 停止所有自动跟随。
- `ToolCard` 在离线时把 partial 覆盖为“未知”，但 `toolGroupSummary` 与组头错误图标不传该覆盖。
- 调用 key 为 `session_id + leaf_id + group_id + tool_call_id`，partial 与正式结果共用；[`timeline-presentation.ts`](../../../pwa/src/lib/pwa/timeline-presentation.ts) 的 `reconcileOrder` 保证已观察条目不因完成时间改变位置。
- [`collapse.tsx`](../../../pwa/src/components/pwa/collapse.tsx) 只在 `open` 变化时播放伸缩动画，已展开内容增长时不重播。

## 界面

### 组头

| 状态 | 组头左侧 | 右侧 |
| --- | --- | --- |
| 折叠，当前工具仍在运行 | 工具名 + 参数摘要（复用 `toolHeaderSummary`） | 当前工具旋转图标 + 错误汇总提示（有失败时）+ 折叠箭头 |
| 折叠，当前工具已结束，但仍有工具运行、缺少闭合信号或展示时间未满 | 保持当前工具名 + 参数摘要 | 当前工具结束状态图标 + 按需错误汇总提示 + 折叠箭头；当前已表示失败时不重复错误图标 |
| 折叠，整批已结束、闭合且展示时间满足 | 分类摘要 | 错误图标（有失败时）+ 折叠箭头，不显示完成对勾 |
| 首次加载的已结束历史工具或离线组 | 分类摘要，不重播调用 | 按需错误图标 + 折叠箭头，离线 partial 不显示旋转图标 |
| 展开 | 分类摘要 | 错误图标（有失败时）+ 折叠箭头；各工具状态显示在下方工具行右侧 |

- 组头排队规则见 C10，实现为 [`tool-group-head.ts`](../../../pwa/src/components/pwa/tool-group-head.ts) 的纯函数：`GROUP_HEAD_QUEUED_VISIBLE_MS` 与 `GROUP_HEAD_MIN_VISIBLE_MS` 都为 0.8 秒，`GROUP_HEAD_MAX_BACKLOG` 为 3 条；停留中的已结束工具显示结束状态图标。展示时间从每条进入组头时开始，切换后重新计时。
- 批次闭合由 [`tool-groups.ts`](../../../pwa/src/components/pwa/tool-groups.ts) 的 `toolBatchClosed` 判断：该组之后的同轮正文／思考或正式 `run_end` 提供边界，但闭合不代表组内工具已经全部结束。不能用 Pi 空闲、下一轮用户消息、文件发布或缺口代替该边界。
- 当前工具变化时，新文字和状态图标从下方进入一次，首次出现不播放；减少动态效果时只淡入、无位移。组头高度不变，长命令单行省略，右侧图标不进入文字裁剪区。
- 分类摘要沿用现有规则（按类别计数、读取等按路径去重、失败与中断计数追加在末尾），运行中的工具也计入。
- 可访问名称包含展开状态、当前命令（如有）与分类摘要；组头不设 live 区域，运行状态仍由各工具行的 `role="status"` 表达。

### 运行状态派生

组头与工具行使用同一状态派生：离线时 partial 统一视为“未知”，不作为当前命令显示，也不计入旋转图标。实现上把现有的离线覆盖传给工具组，不在组头另行推导。

### 展开

- 保留现有标题式工具行和左侧从属竖线；点击工具行打开现有详情阅读器。
- 新调用追加到组内最下面；同一调用的流式更新、正式结果、失败或中断只更新原位置。

### Working 提示

- 文案改为「Working…」，位置与样式沿用原「Pi 正在思考…」。
- C7 表达 Pi 仍在运行，修订背景见 [ADR 的 Working 提示修订](../../adr/20261011-live-tool-grouping.md#working-提示修订2026-10-12)；当前具体状态优先、Working 兜底的规则以 [DESIGN「会话正文」](../../DESIGN.md#组件规则) 为准。本次组头修订不改变该优先级。
- 轮次边界仍按末轮判断：最后一条正式记录决定所属轮；末尾是新发送、尚未回传也未进入 Pi 队列的消息时视为新的一轮，末尾是已进入 Pi 队列的消息时仍属当前轮。
- 残留 partial 的过滤仍用于判定末尾工具组、展开后的自动跟随及当前轮的运行指示。已收到 `run_end` 或不属于末轮的 partial 视为残留；新发送消息后，Pi 空闲期间就已存在的 partial 同样视为残留，Pi 正在输出时发送的消息不触发该规则。

## 分组与身份

### 工具段边界

同一会话与分支范围、同一轮内，相邻工具组成工具段。正文、思考、可见记录、已发布文件和历史缺口打断工具段，不跨边界归并。运行中、成功、失败、中断和状态未知的工具都进入工具组；分组本身不证明执行成功或整轮结束。

### 用户选择优先

- 没有选择：默认收起。
- 用户展开或收起后保持，直到用户再次切换；新增调用、partial 转正式结果、失败、中断、`run_end` 和短暂重连都不重置。
- 刷新后默认收起；不同会话、分支或历史范围之间不复用。

### 组身份与选择继承

- 组的 React key 与选择锚点取组内**最早被观察到**的工具 key；历史向前补齐的工具晚于实时工具被观察，不改变已有组的身份。
- 展开选择记录在切换时组内全部成员的 key 上，组的有效选择取组内成员上最近一次的选择；之后被迟到的正文、文件或缺口拆分时，每一段都继承该选择。
- 实时分组后不再需要 `pinnedKey` 与 `ReaderState.grouped` 的延后合并：工具从出现起即在组内，阅读器按工具 key 取值，关闭后来源控件仍在则回焦，否则回焦列表。

## 滚动与阅读

- 组头内容变化只改变内部内容，不触发会话滚动。
- 用户在工具组属于最后一轮、仍在运行且位于时间线末尾时展开，该展开不加阅读锁，自动跟随继续；其余展开照旧暂停自动跟随（C5）。该属性在展开时确定，之后不随运行状态变化。
- 用户上滑回看时，不因工具更新抢回底部；未读输出沿用现有“最新”入口。
- 工具详情阅读器继续单独持有阅读锁，关闭后恢复有效来源焦点。

## 验收

| 场景 | 预期 |
| --- | --- |
| 第一条工具出现 | 即刻进入默认收起组，组头显示该工具 |
| 只有一条工具 | 成组；工具结束、批次闭合且展示时间满足后显示摘要 |
| 顺序执行 | 组头按开始顺序排队展示；工具之间不提前切到摘要 |
| 并行，后开始的先结束 | 保持当前调用及结束状态，较早工具仍运行时不切摘要，也不循环重播较早调用 |
| 全部结束但没有闭合信号 | 继续显示当前调用，等待同轮后续正文／思考或正式 `run_end` |
| 全部结束且批次闭合 | 最后一条从进入组头起展示满 0.8 秒后切摘要，无完成对勾或旋转图标 |
| 同一批已切到摘要后收到迟到调用 | 更新摘要，不重播调用 |
| 当前调用状态变化 | 状态图标保持右侧，文字在左、箭头最右；失败图标不重复 |
| 手动展开 | 组头显示摘要；新调用追加到底部，组保持展开 |
| 手动收起后新增工具 | 组保持收起 |
| partial 转正式结果 | 不重复工具行，不更换组身份，不丢失展开选择 |
| 运行中末段展开 | 继续自动跟随 |
| 已结束组展开 | 暂停自动跟随 |
| 断线、只读历史中的 partial | 显示未知，不作为当前命令，不显示旋转图标 |
| 历史向前加载 | 历史顺序正确，已有组身份与展开选择不变 |
| 正文、思考、文件或缺口插入 | 按真实边界分段 |
| 打开详情后工具继续更新 | 阅读器内容正确，关闭后恢复有效焦点，组不自动收起 |
| Working 提示 | 当前轮没有实际可见的思考／工具运行提示时立即兜底；完成调用等待批次边界时仍能兜底。具体运行边界与可见性按 DESIGN 验收，隐藏不代替完成确认 |
| 收到 `run_end` | 显示轮末完成时间与状态，并提供批次闭合信号；组内工具结束与展示计时仍须满足，展开选择不变 |
| 减少动态效果 | 组头新文字与状态图标仅淡入，无位移，运行中的旋转提示继续保留 |

自动化验证：

- Node 测试覆盖工具段派生、当前工具、组身份继承与摘要。
- Browser Mode 测试覆盖消息列表与视口：实时分组、展开选择、阅读位置、跟随与焦点。本地只运行直接覆盖改动的测试文件，更广回归以 CI 为准。
- 实施后执行 PWA 类型检查、lint、受影响测试、生产 build、`pnpm check:docs` 与 `git diff --check`。
