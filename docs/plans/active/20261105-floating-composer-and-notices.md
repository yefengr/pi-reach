# 输入区浮层与提示重新设计

本方案记录分阶段实施范围与验收门槛，不描述当前已上线能力。决策与没有采用的方案见 [ADR-20261105](../../adr/20261105-floating-composer-and-notices.md)，事项状态以 [ROADMAP](../../ROADMAP.md) 为准；未实现的部分仍以 [DESIGN](../../DESIGN.md) 现有规则为准。

## 要解决的问题

- 输入区高度随草稿、排队、附件与提示变化，消息列表可视高度随之改变：卡片上沿瞬间跳动，抽屉进出时正文整块跳动。
- 主区顶部的连接、局部错误与运行时提示条占布局，出现时推开正在阅读的正文；连接状态在标题区、提示条与 Toast 三处重复。

## 阶段

| 阶段 | 范围 | 观感变化 |
| --- | --- | --- |
| P0 原型 | 已完成，见 [`docs/prototypes/20261105-floating-composer-notices/`](../../prototypes/20261105-floating-composer-notices/page.html)：输入区浮层（抽屉、附件、提示进出，回看与跟随两种情形）、局部错误卡片、安装提示移位、输入区提示行与主区空态的可评审原型 | 无，只评审 |
| P1 结构 | 输入区改为浮层，列表底部留白随输入区实际高度同步，时间线协调器接入输入区高度变化；高度仍一次到位 | 回看时正文不再被推动，其余不变 |
| P2 过渡 | 抽屉、提示行、附件行改为高度过渡；跟随时逐帧贴底 | 输入区增减平滑 |
| P3 提示 | 删除连接提示条与标题区状态，连接与只读状态移入提示行和主区空态；局部错误改为浮动卡片；安装提示移到侧栏与移动导航底部；Toast 固定位置 | 顶部提示与输入区提示按 ADR 重做 |

P1 与 P2 分开提交：P1 不改变观感，出问题容易定位。P3 可在 P1 合并后独立进行，不依赖 P2。

## 逐项复核

### P1、P2

- 列表底部留白：输入区高度变化时同步，停在底部时最后一条消息完整可见；矮窗口与输入框高度预算不再依赖列表的实际尺寸。
- 回看：抽屉、附件、提示进出时，阅读锚点所在行的位置不变（按整像素比较）。
- 跟随：输入区变高、变矮时逐帧贴底，不出现一帧内的整块跳动；流式输出期间同样成立。
- 发送过渡：本端发送时输入区回缩与气泡进入仍是唯一主动作；回缩只改变底部留白，不再通过锁定输入区外层高度完成。
- 历史前插：顶部插入更早记录时，阅读位置补偿不受输入区高度影响。
- 「最新」入口：仍挂在输入区上沿，随输入区高度移动。
- iOS 键盘与安全区：键盘弹出、收起时输入区贴住可视底部，列表留白同步。
- 减少动态效果：高度过渡退化为一次到位，跟随仍贴底。

### P3

- 断线时机：3 秒内恢复不提示；3 秒后显示「正在重新连接…」；10 秒后显示原因与「立即重试」；恢复后提示行离开，Toast「连接已恢复」只在出现过「无法连接」提示之后显示。
- 无网络不提供重试；Pi 已退出与阅读本地历史时输入框只读，占位文字为「无法发送消息」。
- 未打开会话时 Relay 断线改在主区空态说明，阅读本地历史时不显示连接提示。
- 局部错误卡片不占布局，与 Toast 同时出现时上下排列；列表顶部留白同步，被盖住的第一行仍能滚出来。
- 读屏：提示行与空态承担原提示条的状态播报，同一状态只播报一次；只读输入框具备只读语义。
- 移除标题区状态后，桌面标题与移动标题的可用宽度相应增加。

## 规范同步

DESIGN 与 ARCHITECTURE 随对应阶段的实现一起更新，不提前改写：

| 阶段 | 文档 | 内容 |
| --- | --- | --- |
| P1、P2 | DESIGN「动效」 | 「输入区内的增减」改为高度过渡，并写明回看与跟随的不同处理 |
| P1、P2 | DESIGN「组件规则」 | Composer 条目补充浮层与列表留白同步 |
| P3 | DESIGN「颜色」 | 状态色说明删除标题栏离线与持续断线提示条的例外；`running-line`／`error-line` 的用途删除连接提示条与局部错误条 |
| P3 | DESIGN「间距」 | 删除连接提示条相关档位；运行时提示只保留浏览器能力不支持 |
| P3 | DESIGN「动效」 | 「浮动入口与局部提示」删除连接提示条与占布局提示条，局部错误卡片按浮动入口进出 |
| P3 | DESIGN「布局与导航」 | 桌面标题区右侧只保留刷新应用；运行时提示条的位置改为侧栏与移动导航底部 |
| P3 | DESIGN「反馈呈现」 | 连接、Toast、局部错误与安装四行 |
| P3 | DESIGN「实时与只读历史」 | Pi 退出与阅读本地历史改为只读输入框加提示行 |
| P3 | DESIGN 矮窗口密度 | 删除提示条压缩 |
| P3 | ARCHITECTURE「PWA 反馈状态所有权」 | 连接、局部错误与安装三行的呈现位置；状态所有者不变 |
| P3 | 圆角样式守卫 | 登记局部错误卡片使用 Toast 圆角 |

## 验收门槛

- 时间线视口集成测试覆盖回看不动、跟随逐帧贴底、发送过渡、历史前插与「最新」入口；测试在 Linux CI 上按整像素比较，不依赖过短计时器。
- 提示时机与读屏播报有组件测试；断线计时使用可控时钟。
- 受影响的浏览器组件测试按文件运行，更广的回归以 Pull Request 的 CI 为准。
- iOS 真机录屏覆盖：抽屉进出（回看与跟随）、附件与提示进出、键盘弹出、断线与恢复。普通浏览器与原型不能替代真机观感验收。
