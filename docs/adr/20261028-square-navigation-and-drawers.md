# ADR-20261028: 侧栏、抽屉与页面切换表面改为直角

- 状态：已接受
- 日期：2026-10-28
- 覆盖：[ADR-20261010](20261010-desktop-inset-main.md) 第 7 条的抽屉与页面转场圆角规则

## 背景

侧栏、抽屉和设置页此前采用不同的圆角规则，包括移动全屏页面仅在转场或拖动时显示圆角。调整视觉后，统一这些表面的直角；桌面主区内嵌卡片仍保留原来的圆角。

## 决策

1. 桌面侧栏、移动导航 Drawer、移动电脑选择底部 Drawer、工具与文件阅读器 Drawer，以及设置页，静止、进出和跟手拖动时均为直角。
2. 侧栏展开时桌面主区卡片保留 12px 圆角；侧栏收起及移动布局下主区仍贴边、圆角为 0。
3. 按钮、列表行、内容图片、居中 Modal、Popover、Menu 和 Composer 的圆角规则不变。阴影、遮罩、尺寸、转场、焦点和关闭行为不因本次调整改变。

## 影响

- 抽屉及页面在切换过程中不再显示朝向下层的圆角；桌面阅读器继续通过阴影和遮罩与主区区分。
- 当前视觉规则以 [DESIGN](../DESIGN.md) 为准；原 ADR 保留历史决策背景。
