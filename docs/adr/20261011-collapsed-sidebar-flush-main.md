# ADR-20261011: 收起侧栏后桌面主区贴满窗口

- 状态：已接受
- 日期：2026-10-11

## 背景

[ADR-20261010](20261010-desktop-inset-main.md) 把桌面主区改为内嵌在 `panel` 底上的圆角卡片，侧栏收起后卡片左侧同样与窗口相距 8px。卡片轮廓用于区分侧栏与主区；侧栏收起后已没有需要区分的相邻区域，四周 8px 的 `panel` 色带只占用空间，看起来像遗留的间距。

## 决策

1. 侧栏展开时，主区仍是 ADR-20261010 定义的内嵌卡片，不变。
2. 侧栏收起时，主区四边贴满窗口：外边距为 0，圆角为 0，与移动主区一致，不再露出 `panel` 底。
3. 收起后主区贴着屏幕边缘，安全区由主区内部各层避让一次：会话标题区按顶栏规格把状态栏安全区计入自身（高 `48＋状态栏安全区`），左侧留白为 `56＋左安全区`、右侧为 `8＋右安全区`；阅读列、输入区与提示区按各侧安全区内缩。
4. 收起后展开入口距窗口左缘 `8＋左安全区`，与展开时在品牌行的位置同高；收展过程中只水平移动，不再有 8px 垂直位移。
5. 主区的外边距与圆角随侧栏以同一 220ms 标准曲线过渡。

## 后果

- 取代 ADR-20261010 第 2 条中「侧栏收起后左侧同样相距 8px」与第 5 条中收起后入口「距卡片左缘 8px、随卡片下移」的部分；该 ADR 其余规则不变。
- 收起后状态栏区域显示会话标题区的 `bg` 底色，与移动会话标题区一致。
- 收展时主区四边尺寸都会变化（上下各 8px、左右随侧栏宽度），阅读列和输入区随之重新居中。
