# ADR-20261103: 独立原生标题栏与可调宽悬浮侧栏

- 状态：已接受
- 日期：2026-11-03

## 背景

桌面平铺主区已经消除了旧卡片的外沿色带和标题错位，继续保留。后续安装窗口验收与原型评审表明，窗口控件融合把网页顶部与浏览器原生绘制放在同一视觉区域，但网页并不拥有原生按钮、背景与扩展控件。网页阅读器的遮罩也不能覆盖这些原生内容。继续为融合态增加背景、中线和叠层避让，不能消除这一边界。

本次明确改为独立原生标题栏，并采用已确认的悬浮侧栏外观。侧栏负责品牌和导航，主区负责会话与阅读；不新增共享工具栏，也不恢复主区外层卡片。侧栏宽度允许用户按当前窗口与名称长度调整。

## 决策

1. manifest 保留 `display: standalone`，移除 `window-controls-overlay` 声明及对应 hook、几何样式、拖窗区域与专用测试。网页不模拟原生标题栏；启动与运行时的外观、`theme-color` 同步和普通安全区处理保持不变。
2. 桌面侧栏改为 `panel` 承载的悬浮面板，使用现有 `edge` 发丝线、12px 圆角与 `shadow-float`。左侧留 12px，底部留 38px，再分别避让系统报告的安全区；上方仅避让顶部安全区，不在网页内复制原生栏高度。38px 是本次方案的视觉基线，不是网页测得的原生栏高，也不承诺跨平台上下等距。
3. 侧栏默认宽 280px，可在 240–360px 内调整。右边缘拖动立即跟手、到边界停止，不自动收起；双击恢复默认，提供键盘调宽。偏好仅保存在当前浏览器，与收起状态独立。窄窗口临时限制有效宽度，为主区保留空间，不覆盖偏好；空间恢复后重新使用偏好。移动导航不启用桌面调宽。
4. 品牌仍在侧栏左上，标准档为 20px 标识与 14px／400 字标；面板式收展入口位于品牌行右端，保留 44px 点击区。中部导航独立滚动，底部固定当前电脑和独立设置齿轮。电脑面板从底部向上打开，保留切换、配对、重命名与删除配对。未配对时提供直接配对入口。删除桌面的「当前电脑」「仅保存在此浏览器」常显说明，不改变真实选择或历史保存行为。
5. 收起隐藏整个侧栏，不保留窄轨、阴影或空列；展开入口回到主区左端，标题避让该入口。重新展开恢复当前窗口允许的偏好宽度。主区始终平铺，阅读列与 Composer 最大宽度继续为 680px；双行会话／项目标题、首行操作对齐、消息气泡及 Composer 圆角保持。
6. 网页阅读器、Modal 与遮罩覆盖完整网页，包括品牌行和会话标题，不再为融合态留下不变暗的顶带。原生标题栏及窗口按钮在网页绘制区域之外，仍由浏览器负责。既有 Portal、焦点、Escape、历史记录与阅读锁生命周期不变。

## 替代关系

- 取代 [ADR-20261102](20261102-desktop-flat-window-controls.md) 的 WCO 增强、侧栏贯通全高／无圆角／无阴影、以及侧栏和主区交界分隔规则；保留该记录关于平铺主区、双行标题与具体内容圆角的决策。
- 调整 [ADR-20261028](20261028-square-navigation-and-drawers.md) 的桌面侧栏直角规则。移动导航、工具与文件阅读器 Drawer、设置页继续保持既有直角和转场模型。
- 保留 [ADR-20260929](20260929-sidebar-toggle-placement.md) 的入口归属：展开时在品牌行右端，收起后在标题区左端；图标改为面板式，并随悬浮侧栏边界定位。

## 后果与验证边界

- 侧栏形态与调宽只影响桌面导航空间，不改变协议、Relay、Extension、设备配对、活动 Pi 选择或本地历史模型。
- 宽度偏好与实际宽度分开计算；取消或中断拖动须释放捕获及全局拖动状态，不写入未完成偏好。具体键位、限制公式与尺寸统一维护在 [DESIGN](../DESIGN.md#侧栏宽度)，不在此重复维护。
- 自动化须覆盖宽度边界、偏好恢复、取消与卸载、收展身份保持、导航底部固定、移动隔离、普通安全区和叠层生命周期，不能仅删除 WCO 测试后宣称替代验收完成。
- 普通浏览器或 HTML 原型无法证明真实安装窗口的原生外观。旧安装对 manifest 更新可能滞后，普通刷新未必立即移除 WCO 开关；独立标题栏、原生控件／拖窗、明暗主题与安装更新行为仍需真实安装窗口验收。
