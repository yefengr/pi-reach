# ADR-20261010: 桌面主区改为内嵌圆角卡片

- 状态：已接受
- 日期：2026-10-10

## 背景

桌面布局原为侧栏与主区都贴满窗口：侧栏 `panel`（浅色 `#F7F7F7`）与主区 `bg`（浅色 `#FFFFFF`）直接相接，不加分割线。浅色主题下两者只差一级亮度，分区边界偏弱，整体显得平。

讨论过让侧栏本身变成圆角卡片或带阴影的悬浮卡片，但与现有规则冲突：

- 页面内元素（侧栏、消息、输入区）不用阴影，阴影只用于 Popover、Menu、Toast、Modal 等浮层；侧栏带阴影后会被误读为可关闭的叠层。
- 侧栏是贴边整块表面（圆角为 0），并负责把 `panel` 底色延伸进状态栏与左安全区；悬浮后这些区域会露出另一种底色。

对比稿见 [`docs/prototypes/20261010-desktop-inset-main/`](../prototypes/20261010-desktop-inset-main/page.html)。

## 决策

1. 视口宽度 ≥ 768px 时，应用底色改为 `panel`，侧栏保持原样（贴边、无圆角、无阴影）。
2. 主区成为内嵌卡片：`bg` 底、圆角 `--pwa-radius-lg`（12px），上、右、下与窗口边缘相距 8px，侧栏收起后左侧同样相距 8px；不加阴影，也不加边框。
3. 卡片不贴屏幕边缘，按「不贴边叠层」口径与安全区取较大值（`max(8px, 安全区)`），卡片内部不再叠加安全区：会话标题区固定 48px，不再包含状态栏高度。
4. 会话标题区保持 48px，不为对齐侧栏品牌行而压缩；侧栏未避让状态栏时，卡片内标题比「Pi Reach」低 8px。状态栏安全区不小于 8px 时，两者重新同一中线。
5. 收展入口展开时仍在侧栏品牌行右端；收起后位于卡片标题区左端（距卡片左缘 8px），随卡片一起下移，收展过程中以同一 220ms 标准曲线同时移动水平与垂直位置。
6. 移动布局（< 768px）主区仍贴满屏幕。
7. 从侧边滑入的面板统一为「朝向下层的一侧两角 12，贴屏幕的一侧为直角」，与底部 Drawer 上沿一致：
   - 移动导航 Drawer：右侧两角，始终显示。
   - 桌面工具与文件阅读器 Drawer（720px）：左侧两角，始终显示。
   - 设置页（桌面与移动）、移动全屏工具与文件阅读器：静止时铺满屏幕，圆角会在角上露出下层界面，因此只在进出转场与跟手拖动期间显示左侧两角圆角，与设置页阴影只在转场期间出现的规则一致。

## 后果

- 侧栏与卡片四周连成一片 `panel` 底，分区靠卡片轮廓表达，不再依赖两级底色直接相接。
- 浅色主题下白色卡片与 `#F7F7F7` 底的对比较弱，卡片边缘主要靠圆角和亮度差辨认；需要更清楚的轮廓时可再加 1px `line` 边框。
- 主区在上、右、下各少 8px；阅读列和输入区最大宽度不变，只在窄桌面下略早触及 gutter。
- 桌面状态栏区域现在显示侧栏与卡片上方的 `panel` 底色；`theme-color` 仍跟随 `bg`，浏览器标签页工具栏颜色可能与卡片上方的 8px 色带不同。
- 补充 [ADR-20260929](20260929-sidebar-toggle-placement.md)：收起后的入口位置改为相对卡片计算，并增加 8px 垂直位移；该 ADR 的其余规则不变。
