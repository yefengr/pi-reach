# ADR-20261028: 主屏 PWA 改用系统实色状态栏

- 状态：已接受
- 日期：2026-10-28

## 背景

主屏 PWA 原先设置 `viewport-fit=cover` 与 `black-translucent`，页面延伸到状态栏下方，状态栏区域透出下方顶栏的颜色。iOS 27 起，从桌面图标启动的 PWA 会在状态栏下方加一段向下延伸的模糊，盖住移动顶栏的菜单、会话名、连接状态与信息按钮，正文不受影响。

`theme-color`、`apple-mobile-web-app-status-bar-style` 与 `body` 背景色都不能去掉这段模糊。WebKit 的处理方式是：在页面顶边中点下方约 4px 处命中检测，命中元素或其祖先为 fixed 时，按其背景色在状态栏区域铺一层实色视图，同时隐藏模糊；这层视图只在状态栏属于页面之外的遮挡区域时出现。真机诊断结果一致：保留 `viewport-fit=cover` 时，顶部 fixed 元素无法去掉模糊；去掉之后，状态栏变成该元素的颜色，顶栏清晰。

## 决策

1. viewport 不再设置 `viewport-fit=cover`，页面从状态栏下方开始，状态栏由系统铺成实色。
2. 应用壳放一个只供取色的 fixed 真实元素（`.pwa-status-backdrop`）：满宽，高 12px，位于所有叠层之上；背景只裁到零高的内容盒，不绘制、不接收点击。伪元素命中后按宿主元素处理，不能替代真实元素。
3. 状态栏颜色取状态栏下方顶栏的底色：移动端、侧栏收起与设置页为 `bg`，桌面侧栏展开与移动导航打开时为 `panel`；Modal 等遮罩不改变颜色。
4. 状态栏、左右安全区的避让规则和 token 保留，在系统报告安全区的环境中继续生效。

## 后果

- 取代 [DESIGN](../DESIGN.md#状态栏与顶部区域) 中「页面延伸到状态栏下方、状态栏透出下方界面」与「叠层遮罩覆盖状态栏」的规则。[ADR-20261010](20261010-desktop-inset-main.md) 与 [ADR-20261011](20261011-collapsed-sidebar-flush-main.md) 中状态栏显示 `panel`／`bg` 的结论不变，改由背景条的颜色实现。
- 打开 Drawer 或 Modal 的遮罩时，主屏 PWA 的状态栏不随遮罩变暗。
- iOS 横屏时，页面预计不再延伸进刘海一侧，由系统留出该区域。这一点和 iOS 26 及更早版本的主屏表现一样，尚未经真机验证。
