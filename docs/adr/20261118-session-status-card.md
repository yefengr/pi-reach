# ADR-20261118：桌面会话状态卡片与阅读列让位

- 状态：已接受
- 日期：2026-11-18
- 范围：桌面会话工作区，不修改详情阅读器的宿主或交互

## 背景

远程阅读 Pi 会话时，用户需要随时查看上下文占用、累计用量与费用。把这些数值放入标题区会挤压会话名，也会令布局随数据更新。把状态放入详情阅读器则需要主动打开，不能在阅读会话时一并查看。

## 决策

打开会话时，桌面按主区可用宽度在标题区右下方显示常驻只读状态卡片。卡片和右侧留白固定占 260px，阅读列在主区可用左缘与卡片左缘之间居中。侧栏展开时，主区从侧栏右缘开始。侧栏收起时，主区从窗口左缘开始。宽度不足或未打开会话时隐藏卡片，阅读列在整个可用主区居中。离线、加载和失败仅改变卡片内容，让正文位置不随会话状态变化。卡片不提供折叠入口、分栏拖拽或列宽偏好。用户可在设置的「工作区」分区关闭卡片，正文随即回到主区中央。

[ADR-20261018](20261018-reader-drawer-only.md) 取消的是工具、文件等详情的非模态第二列。状态卡片不承载详情、不接收焦点，也没有需要在分栏与 Drawer 之间迁移的正文、滚动位置或 history。桌面详情仍由原有阅读器 Drawer 覆盖工作区及卡片；移动会话状态抽屉与详情阅读器互斥，不复用详情宿主。

## 影响

侧栏收展、调宽与视口变化须按实际空间更新卡片显隐，并保持消息、Composer、「最新」、局部错误和 Toast 对齐。会话、草稿与阅读器保持各自的生命周期。布局与交互细节见 [DESIGN](../DESIGN.md#布局与导航)。
