# ADR-20261118：桌面会话状态卡片与阅读列让位

- 状态：已接受
- 日期：2026-11-18
- 范围：桌面会话工作区，不修改详情阅读器的宿主或交互

## 背景

远程阅读 Pi 会话时，用户需要随时查看上下文占用、累计用量与费用。把这些数值放入标题区会挤压会话名，也会令布局随数据更新。把状态放入详情阅读器则需要主动打开，不能在阅读会话时一并查看。

## 决策

桌面主区宽度足够时，标题区下方右侧常驻只读状态卡片。能让阅读列保持居中就保持居中；否则正文、输入区和随列对齐的浮动提示共同左移，刚好让出卡片空间。阅读列移至主区 gutter 仍放不下时，隐藏卡片，恢复居中。不增加折叠入口、分栏拖拽或列宽偏好。

[ADR-20261018](20261018-reader-drawer-only.md) 取消的是工具、文件等详情的非模态第二列。状态卡片不承载详情、不接收焦点，也没有需要在分栏与 Drawer 之间迁移的正文、滚动位置或 history。桌面详情仍由原有阅读器 Drawer 覆盖工作区及卡片；移动会话状态抽屉与详情阅读器互斥，不复用详情宿主。

## 影响

桌面主区不再一律以主区中心对齐阅读列。侧栏收展、调宽与视口变化须按实际空间重新计算，并保持消息、Composer、「最新」、局部错误和 Toast 对齐；卡片消失不影响正式会话、草稿或阅读器。布局与交互细节由 [DESIGN](../DESIGN.md#布局与导航) 维护。
