# ADR-20261001: 中性底色与雾蓝主色

- 状态：已接受
- 日期：2026-10-01

## 背景

[品牌刷新方案](../plans/active/20260925-pi-reach-brand-refresh.md)确认的配色是「钢雾蓝」：主色 `#4C658D`，中性色按蓝灰调配，蓝色负责主操作、链接、焦点和选中。

落地后的界面整体偏灰、发闷。核对 token 发现两个原因：

- 主色的 OKLCH 纯度只有 0.071（深色版 `#A9C3E6` 为 0.057），低于完成、运行、错误等状态色，是界面里最灰的颜色；空草稿时半透明的发送按钮看起来接近灰色。
- 各级中性色都带 197–237° 的冷蓝色调（如深色主区 `#202325`），与主色色相接近，深色主题尤其明显；当前会话、菜单当前项、提示框等又使用浅蓝底，主色从按钮扩散到了背景。

用 README 截图的演示数据在真实组件上实拍对照了改前改后，以及原色、纯度 0.120 的「钢蓝提纯」和在原色基础上提纯、加深、偏青、偏紫的四个候选。

## 决策

1. 中性色全部改为无彩灰（R=G=B），亮度与原各级基本一致：浅色主区与设置页为纯白 `#FFFFFF`、侧栏 `#F7F7F7`；深色主区与设置页为 `#1E1E1E`，不用纯黑，避免浅字光晕、OLED 滚动拖影，以及无法再用更暗的层次区分代码块。
2. 主色改为「雾蓝」：保持原色的色相与亮度，只把纯度从 0.071 提到 0.090，浅色 `#446396`、深色 `#98B8E6`。favicon、安装图标与字标同步换色。
3. 主色只用于主操作、文字按钮与链接、焦点轮廓、单选框选中点和在线／新回复圆点。当前会话、当前电脑和菜单当前项改用新增的中性 `selected` 底与 `ink` 文字，删除 `accent-wash`；设置单选项选中时为 1px `ink` 描边；安装提示框、状态标签、品牌标识、工具名、行内代码与命令块改用中性色。
4. 状态色（完成、运行、错误）与语法色的规则不变；对比度约束不放宽，由 `pwa-theme-contrast` 测试继续校验。

## 后果

- 背景不再带色调，蓝色只出现在可操作的位置，界面更干净，按钮也更醒目。
- 覆盖品牌方案「品牌」中「蓝色负责……选中」、「明暗配色」表与「场景用法」中选中态和行内代码的描述，以及 DESIGN 中的对应规则；两处已同步更新。
- 已发布的安装图标会随下次部署更新；已安装的 PWA 是否刷新图标取决于各平台的清单更新策略。
