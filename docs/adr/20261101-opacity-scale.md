# ADR-20261101: 透明度刻度与半透明文字选区

- 状态：已接受
- 日期：2026-11-01
- 覆盖：[ADR-20261101 发丝线分隔](20261101-hairline-concentric-radii.md)第 1 条中深色常规分隔色 `#FFFFFF2E` 与「叠在 `bg` 上与原 `line` 同深」；文字选区原有的实心 `accent`＋`on-accent`

## 背景

参照 iOS 调整圆角之后，评审中发现文字选区仍是实心雾蓝、文字反白，在长段选择时像一块色块，也盖住了气泡、代码块等底色差异和链接、次级文字的颜色层次。浏览器的 `::selection` 不支持圆角，可调的只有颜色。

准备给选区设半透明色时盘点了现有透明度：分隔、遮罩、阴影各自写 8 位 hex，`color-mix` 比例与 `opacity` 中间值散落在主题、全局样式和脚本里，共 4 类 13 个取值，没有统一刻度，也没有守卫。其中危险入口悬停底按 10% 混合，浅色错误色文字实为约 4.2:1，注释中的「≥ 4.5:1」并不成立。

## 决策

1. 建立透明度刻度：32% 以内步长 4%，以上步长 8%。半透明色、`color-mix` 比例与元素透明度都只取刻度档位，现有取值就近吸附，等距时取较轻一档：深色常规分隔 18% → 16%（改为「取叠在 `bg` 上最接近 `line` 的档位」）、深色遮罩 55% → 56%、阴影浅色 10% → 8% 与深色 30% → 28%、发送／停止禁用 0.5 → 0.48、内容淡入起点 0.35 → 0.32。
2. 危险入口悬停底改为混入 4% 错误色，浅色错误色文字约 4.6:1；悬停变化变轻，仍有按压缩放反馈，只在可悬停设备上出现。
3. 元素透明度的中间值改为具名 token `--pwa-opacity-*`；动效端点 0 与 1 不算刻度。脚本必须保留的副本由守卫校验与主题同值。
4. 文字选区改为主色半透明底 `--pwa-selection`（浅色 20%、深色 24%），不改文字颜色。正文级文字在选区上 ≥ 4.5:1；次级文字、链接与代码行号 ≥ 3:1，因为选区只在选中期间出现；若要求链接也 ≥ 4.5:1，透明度需降到 12%，选区几乎不可见。

## 影响

- 深色分隔线、遮罩与两主题阴影有 1～2 个百分点的变化；浅色阴影略轻。
- `pwa-theme-contrast` 新增刻度、选区与危险悬停底对比度校验；`pwa-style-guard` 禁止主题文件外的函数色与 `opacity` 中间值；`pwa-script-token-guard` 校验淡入起点与主题同值。
- 当前规则以 [DESIGN「透明度」](../DESIGN.md#透明度)为准。

## 补充决策：按 iOS 27 拆分行间分隔与浮层外框（2026-11-01）

边框、分隔与圆角原先参照 iOS 26。核对 iOS 27 后，变化集中在两处：系统分隔色明显调淡（模拟器读取值：浅色 `#3C3C43` 由 29% 降到 12%，深色 `#545458` 由 60% 降到 50%）；Liquid Glass 浮层改用加深的边缘、少用投影。圆角与同心规则未见调整，滚动边缘改回顶部硬边加分隔线、底部不处理，与当前实现一致。

1. 发丝线按用途拆成两个 token：`--pwa-separator` 只用于行间与分区分隔，`--pwa-edge` 用于浮在内容上的表面外框（Composer、菜单、Popover、电脑面板、Toast、「最新」、排队面板、运行时提示等）和 Markdown 表格格线。两者都随 `--pwa-hairline` 切换常规档与发丝线档。
2. `separator` 调淡：浅色 12%/8%、深色 16%/12%（发丝线档/常规档）。比 iOS 27 的等效值（浅色约纯黑 9%，深色叠 `#1E1E1E` 约纯白 12%）略深一档：桌面 Chrome 只能用 1px 常规档，1 倍屏上 8% 已近可见下限；浅色 `bg` 与 `surface` 同为白色，列表更依赖分隔线；深色底不是纯黑。
3. `edge` 沿用原分隔色：浅色 20%/12%、深色 24%/16%。深色 Composer 不用阴影，只靠外框与明度区分；数据表格需要清楚的格线。
4. 取消决策 1 中「常规档取叠在 `bg` 上最接近 `line` 的档位」，`separator` 不再与 `line` 绑定。阴影、遮罩、选区与透明度刻度不变；不引入玻璃材质，文字层级仍用不透明灰。

影响：行间分隔在所有平台变轻；浮层外框与表格观感不变。对比度测试改为校验两组 token 的档位关系（每档 `edge` 比 `separator` 深、发丝线档比常规档深），样式守卫允许发丝线配 `separator` 或 `edge`。桌面 Chrome 1 倍屏上的 8% 常规档与深色设置页分组行间线需真机验收。
